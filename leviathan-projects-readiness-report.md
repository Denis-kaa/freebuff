### 2.1. SavdaBot — уровень 3 → кандидат №1 на стенд

- **Суть:** AI-консультант маркетплейса savda.ru. FastAPI + ChromaDB RAG + Groq, HQ-панель с авторизацией.

- **Стенд:** **да** — сильный коммерческий RAG-кейс. Подтвердить статус клиента и разрешение на упоминание.

**План до прода:**
1. Сменить HQ-креды, секреты → secrets-vault, README очистить от паролей.
2. Прогнать тесты в CI-режиме локально, зафиксировать green.
3. Пересобрать RAG-индекс ChromaDB отдельной командой-джобой (идемпотентной).
4. Деплой: venv/systemd или docker на whimco, uvicorn за nginx, healthcheck `/health`.
5. Логи + ротация, бэкап БД/индекса, мониторинг упавших запросов LLM.

## 4. Общий производственный контур (для всех новых деплоев)

1. **Секреты:** только secrets-vault, `.env.example` в репо без реальных значений.
2. **Deploy:** systemd-юнит на whimco (по образцу `profile-site.service`) или docker-compose; healthcheck-эндпоинт обязателен.
3. **Nginx:** отдельный location/порт на проект, дефолтный сайт GapirAI не трогать.
4. **Логи:** journald + ротация, correlation-id для мультиагентных потоков.
5. **Бэкапы:** SQLite/PG-дампы ежедневно, шифрованные.
6. **Наблюдаемость:** счётчик ошибок LLM-вызовов и стоимость токенов — минимум.
7. **Порядок:** тесты green → деплой на 127.0.0.1 → проверка → открытие порта.
