# Сценарий: Настройка AI агента

## Промт для freebuff

```
Настрой AI агента {agent_name***REMOVED*** для работы с проектом в {project_path***REMOVED***.

Что нужно сделать:
1. Создать конфигурационный файл агента под проект
2. Настроить правила и конвенции проекта
3. Подготовить контекст из документации проекта
4. Протестировать базовые команды

Тип агента: {agent_type***REMOVED*** (Claude Code / OpenClaw / Codebuff / Qwen IDE)
Особенности проекта: {особенности***REMOVED***

Напиши необходимые файлы конфигурации.
```

## Варианты

| Агент | Конфиг | Особенности |
|-------|--------|-------------|
| Claude Code | CLAUDE.md | правила, контекст |
| Codebuff | AGENTS.md | инструкции, файлы |
| OpenClaw | .openclaw/config.yaml | скиллы, модели |
| Qwen IDE | .qwen/memory | memories, задачи |
