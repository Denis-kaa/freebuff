# Сценарий: Интеграция API  

## Описание задачи

Интеграция с внешним API: отправка данных, получение информации, синхронизация.

## Технические требования

```yaml
стек:
  python: 3.11+
  библиотеки:
    - httpx/requests  # HTTP клиент
    - pydantic  # модели
    - tenacity  # ретраи
  вывод: json/console/file
```

## Промт для freebuff

```
Разработай интеграцию с API {название_сервиса***REMOVED***.

Эндпоинты API:
{описание_эндпоинтов***REMOVED***

Что нужно сделать:
1. Аутентификация ({тип: Bearer/API Key/OAuth***REMOVED***)
2. {действие1***REMOVED***
3. {действие2***REMOVED***
4. Сохранение результата в {формат***REMOVED***

Требования:
- Python 3.11+
- httpx для HTTP запросов
- pydantic для валидации
- tenacity для ретраев (3 попытки с exponential backoff)
- Логирование через logging

Напиши полный код класса-клиента с type hints.
```

## Варианты

| Тип | Примеры | Сложность |
|-----|---------|-----------|
| Простой GET | Погода, курс валют | низкая |

| Очередь | Вебхуки + Celery/ARQ | высокая |
| OAuth2 | Google, GitHub, Telegram | средняя |
