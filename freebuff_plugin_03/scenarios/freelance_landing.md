# Сценарий: Сайт-визитка / Лендинг  

## Описание задачи

Разработка одностраничного сайта (landing page) для представления услуг, товаров или портфолио.

## Технические требования

```yaml
стек:
  html/css: чистый (без фреймворков)
  js: vanilla (опционально)
  адаптивность: да (mobile-first)
  хостинг: GitHub Pages / Netlify / любой
  seo: базовый (meta, og tags)
```

## Промт для freebuff

```
Разработай landing page для {тип_сайта***REMOVED***.

Требования:
1. Технологии: HTML5 + CSS3 + vanilla JS
2. Секции:
   - Hero (заголовок, подзаголовок, CTA кнопка)
   - О нас / О продукте
   - Преимущества (3-4 карточки)
   - {доп_секция***REMOVED***
   - Контакты / Форма
3. Адаптивный дизайн (mobile-first)
4. Анимации на CSS (появление блоков при скролле)
5. Минимальный JS: плавный скролл, форма
6. Цветовая схема: {цвета***REMOVED***

Формат: один HTML файл со встроенным CSS и JS.
```
