# Сценарий: Парсер Telegram  \n

## Описание задачи

Разработка парсера Telegram каналов и чатов для сбора сообщений, медиафайлов и метаданных.
Парсер работает через MTProto (Telethon) и может мониторить каналы в реальном времени.

## Технические требования

```yaml
стек:
  python: 3.11+
  библиотеки:
    - telethon 1.44+  # MTProto клиент
    - pydantic  # модели данных
    - sqlalchemy/aiosqlite  # БД
    - asyncio  # асинхронность
  хранение: sqlite | postgresql
  вывод: json | csv | база данных
```
