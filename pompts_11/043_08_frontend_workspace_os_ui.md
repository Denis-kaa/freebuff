## ВИЗУАЛЬНЫЕ ПРАВИЛА (КРИТИЧНО)

1. **Никаких эмодзи в UI.** Все иконки — из lucide-react. Для AI-ассистента используй анимированную SVG-сферу с градиентом cyan→magenta (пульсация через framer-motion), без внешних картинок.

3. **Glassmorphism:** все карточки — `bg-white/5 backdrop-blur-xl border border-white/10`. При hover — `bg-white/10` + `box-shadow: 0 0 20px rgba(0, 255, 255, 0.3)`.

4. **Анимации:** framer-motion для появления элементов (stagger children), плавные переходы 0.3s cubic-bezier.

5. **Drag-and-drop визуал:** при перетаскивании — scale(1.05) + усиленное свечение. Зона drop — пунктирная рамка cyan.

6. **Никаких видео-фонов, 3D-рендеров и стоковых фото.** Только CSS/SVG + одна опциональная картинка аватара Buffy (пока используй placeholder-сферу).
