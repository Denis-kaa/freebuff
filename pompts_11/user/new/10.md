PROMPT 10 — FILES / DOCUMENTS / ATTACHMENTS ENGINE

Контекст

В предыдущих этапах реализованы:

- Workspace;
- Users / Roles / Permissions;
- Projects;
- Project Items;
- Production;
- Tasks;
- Dashboard Engine;
- Plug & Play Widgets;
- Calendar;
- Search / Filters / Saved Views;
- Custom Fields;
- Formula Engine;
- Notifications;
- Automation Engine;
- Risk Engine;
- Event System;
- Import / Export.

Теперь необходимо реализовать универсальную систему файлов и документов.

Главная идея:

«Проект должен содержать не только структурированные данные, но и все связанные рабочие материалы.»

Например:

Проект P024
│
├── 📄 Договор
├── 💰 Счёт
├── 🎨 Макет
├── 🎨 Макет v2
├── 📦 Техмакет
├── 📦 Фото сигнала
├── 📑 УПД дизайн
├── 📑 УПД сигнал
├── 📑 УПД производство
└── 📊 Excel

     │

     ├── TECH MOCKUP
     ├── SIGNAL
     ├── PHOTOS
     ├── UPD
     ├── CONTRACT
     └── OTHER

Главный принцип:

«File — это физический объект хранения. Document — бизнес-сущность. Attachment — связь файла с любой сущностью системы.»

Не смешивать эти три понятия.

Второй принцип:

«Файлы приватные по умолчанию. Доступ контролируется Workspace + RBAC + permissions.»

Третий принцип:

«Файловая система должна быть универсальной и использоваться не только Projects, но и Tasks, Items, Documents и будущими модулями.»

Четвёртый принцип:

«Новые версии файлов не уничтожают старые. История должна быть восстановима.»

Пятый принцип:

«Все действия с файлами генерируют события, чтобы Dashboard, Notifications и Automation Engine могли использовать их без дублирования бизнес-логики.»
