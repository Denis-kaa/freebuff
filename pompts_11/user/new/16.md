## GOOGLE SHEETS SYNC ARCHITECTURE

### Принцип синхронизации

**MVP реализует:**
1. **One-way sync (App → Google Sheets)** — автоматически при изменении в приложении
2. **Manual sync (Google Sheets → App)** — по кнопке пользователя
3. **Conflict detection** — при обнаружении изменений в Google Sheets

**НЕ реализует:**
- Realtime двустороннюю синхронизацию
- Автоматический polling Google Sheets
- CRDT/Operational Transformation

## SYNC MAPPING TABLE

Создать таблицу для отслеживания синхронизированных записей:

```sql
google_sheets_sync_mappings
├── id (UUID)
├── workspace_id (UUID)
├── project_id (UUID)
├── google_sheet_id (string)
├── google_row_id (string) — уникальный идентификатор строки
├── last_synced_at (timestamp)
├── last_synced_by (UUID) — user_id
├── sync_status (enum): synced, conflict, error
├── conflict_data (JSONB) — данные конфликта
├── created_at (timestamp)
├── updated_at (timestamp)
```

**Важно:** НЕ использовать номер строки как единственный идентификатор, потому что пользователь может:
- сортировать таблицу
- вставлять строки
- удалять строки

Использовать стабильный идентификатор:
- `display_id` (например, P024) в специальной колонке Google Sheet
- или UUID в скрытой колонке

## ONE-WAY SYNC (App → Google Sheets)

### Trigger

При изменении проекта в Workspace:

```python
# Pseudo-code
@event_handler("project.updated")
async def sync_to_google_sheets(event):
    project = event.payload
    
    # Check if project is synced to Google Sheets
    mapping = await get_sync_mapping(project.id)
    
    if not mapping:
        return  # Project not synced, skip
    
    # Check if Google Sheet is connected
    integration = await get_google_integration(project.workspace_id)
    
    if not integration:
        return  # No Google integration, skip
    
    # Update Google Sheet
    try:
        await update_google_sheet_row(
            sheet_id=integration.sheet_id,
            row_id=mapping.google_row_id,
            data=project_to_sheet_row(project)
        )
        
        # Update sync status
        mapping.last_synced_at = now()
        mapping.sync_status = "synced"
        await save_mapping(mapping)
        
    except Exception as e:
        # Log error, don't break main flow
        mapping.sync_status = "error"
        mapping.conflict_data = {"error": str(e)}
        await save_mapping(mapping)
```

### Events to Sync

Синхронизировать при следующих событиях:
- `project.created` — создать новую строку
- `project.updated` — обновить строку
- `project.deleted` — удалить строку (или пометить как архивную)
- `project_item.updated` — обновить связанные данные
- `task.created/updated/completed` — обновить задачи
- `payment.updated` — обновить оплату

### Rate Limiting

Google Sheets API имеет лимиты:
- 60 requests per minute per user
- 300 requests per minute per project

Реализовать queue:

```python
# Pseudo-code
class GoogleSheetsSyncQueue:
    async def enqueue(self, project_id, action, data):
        await redis.lpush("google_sync_queue", {
            "project_id": project_id,
            "action": action,
            "data": data,
            "timestamp": now()
        })
    
    async def process_queue(self):
        while True:
            item = await redis.brpop("google_sync_queue", timeout=1)
            if item:
                await process_sync_item(item)
                await asyncio.sleep(1)  # Rate limiting
```

### Batch Updates

Если пользователь массово меняет проекты (например, через bulk update), не делать 100 отдельных API calls:

```python
# Pseudo-code
async def batch_sync_to_google(projects):
    # Group by Google Sheet
    sheets = group_by_sheet(projects)
    
    for sheet_id, sheet_projects in sheets.items():
        # Batch update (up to 100 rows per request)
        await google_sheets_api.batch_update(
            sheet_id=sheet_id,
            rows=[project_to_sheet_row(p) for p in sheet_projects]
        )
```

При нажатии **[ Sync from Google Sheets ]**:

1. **Read Google Sheet**

## CONFLICT DETECTION

### How to Detect

Для каждого поля отслеживать `last_modified_at`:

```python
# Pseudo-code
class SyncConflictDetector:
    async def detect_conflicts(self, workspace_project, google_row):
        conflicts = []
        
        for field in SYNCABLE_FIELDS:
            workspace_value = getattr(workspace_project, field)
            google_value = google_row.get(field)
            
            workspace_modified = workspace_project.get_field_modified_at(field)
            google_modified = google_row.get(f"{field}_modified_at")
            
            if workspace_modified and google_modified:
                if workspace_modified > google_modified and workspace_value != google_value:
                    # App changed after Google
                    conflicts.append({
                        "field": field,
                        "app_value": workspace_value,
                        "google_value": google_value,
                        "type": "app_changed"
                    })
                elif google_modified > workspace_modified and workspace_value != google_value:
                    # Google changed after App
                    conflicts.append({
                        "field": field,
                        "app_value": workspace_value,
                        "google_value": google_value,
                        "type": "google_changed"
                    })
                elif workspace_modified == google_modified and workspace_value != google_value:
                    # Both changed at same time
                    conflicts.append({
                        "field": field,
                        "app_value": workspace_value,
                        "google_value": google_value,
                        "type": "simultaneous"
                    })
        
        return conflicts
```

### Conflict Resolution UI

Для каждого конфликта показать:
- Название поля
- Значение в App
- Значение в Google Sheets
- Дата изменения в App
- Дата изменения в Google Sheets
- Кнопки: [ Use App ] [ Use Google ] [ Skip ]

## ERROR HANDLING

### Google API Errors

```python
# Pseudo-code
async def handle_google_api_error(error):
    if error.code == 403:
        # Permission denied
        return "Google Sheets access denied. Please reconnect."
    
    elif error.code == 429:
        # Rate limit exceeded
        return "Too many requests. Please wait a minute."
    
    elif error.code == 404:
        # Sheet not found
        return "Google Sheet not found. It may have been deleted."
    
    else:
        return f"Sync error: {error.message}"
```

### Sync Errors

Если синхронизация не удалась:
- НЕ ломать основную операцию в Workspace
- Записать ошибку в sync log
- Показать пользователю в UI
- Предложить retry

## ГЛАВНЫЙ АРХИТЕКТУРНЫЙ ПРИНЦИП

Excel не должен становиться вторым Workspace.
Google Sheets не должен становиться вторым Workspace.

Они являются:

```
   EXTERNAL FORMATS
          │
   ┌──────┴──────┐
   ▼             ▼
 Excel       Google Sheets
   │             │
   └──────┬──────┘
          ▼
      INTEGRATION
          │
          ▼
      WORKSPACE
          │
          ▼
      PostgreSQL
```

Workspace остаётся главным источником данных.
Интерфейс остаётся Plug & Play.
А Excel и Google Sheets становятся удобными шлюзами для старого и внешнего рабочего процесса.

**Синхронизация — это мост, а не замена.**

</writeFile>

✅ **Manual sync (Google → App)** — по кнопке пользователя  
✅ **Conflict detection & resolution UI** — предпросмотр и выбор при конфликтах
✅ **Sync status indicator** — 🟢/🟡/🔴 в Project Drawer
✅ **Sync mapping table** — стабильная идентификация строк через UUID
✅ **Rate limiting & queue** — защита от Google API лимитов
✅ **Sync log** — история всех синхронизаций
✅ **Background worker** — не блокирует HTTP requests

- Sorting

Главный принцип:

«Workspace является источником структурированных данных. Excel и Google Sheets — внешние форматы обмена, а не основа архитектуры.»

Нельзя строить внутреннюю БД вокруг Excel-строк и Excel-формул.
