PROMPT 08 — NOTIFICATIONS & AUTOMATION ENGINE

Контекст

В предыдущих этапах реализованы:

- Workspace;
- Projects;
- Project Items;
- Production;
- Tasks;
- Documents;
- Dashboard Engine;
- Plug & Play Widgets;
- Calendar & Events;
- Import / Export Excel;
- Google Sheets;
- Search;
- Filters;
- Saved Views;
- Custom Fields;
- Formula Fields.

Теперь необходимо реализовать универсальный Notifications & Automation Engine.

Главная идея:

«Пользователь не должен постоянно проверять таблицу вручную. Система должна сама обнаруживать события, выполнять разрешённые автоматизации и сообщать пользователю только о том, что действительно требует внимания.»

2. Event Bus

Не зашивать автоматизации непосредственно в CRUD-код.

Например, не делать:

if project.deadline_changed:
    ...

в каждом endpoint.

Создать события:

project.created
project.updated
project.status_changed

project.deadline_approaching
project.deadline_overdue

task.created
task.completed
task.overdue

payment.updated

item.created
item.status_changed

document.uploaded
document.completed

ГЛАВНАЯ ЦЕЛЬ

После этого этапа приложение должно перестать быть просто системой хранения данных.

Оно должно работать по принципу:

ПОЛЬЗОВАТЕЛЬ
      ↓
создал проект
      ↓
СИСТЕМА НАБЛЮДАЕТ
      ↓
обнаруживает события
      ↓
проверяет условия
      ↓
выполняет разрешённые действия
      ↓
уведомляет пользователя

Например:

P024
Дедлайн через 1 день
        ↓
Проект ещё не отгружен
        ↓
Risk = HIGH
        ↓
Создать задачу
"Проверить готовность тиража"
        ↓
Уведомить Дениса
        ↓
Показать на Dashboard

Главный принцип:

«Automation Engine должен быть универсальным. Не писать отдельный код под каждое новое правило. Пользователь должен собирать автоматизации из блоков WHEN → IF → THEN.»

И ещё один принцип:

«Автоматизация не должна быть магией. Пользователь всегда должен понимать, почему она сработала, что она сделала и какое событие её запустило.»
