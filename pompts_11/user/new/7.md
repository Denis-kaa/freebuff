PROMPT 07 — SEARCH / FILTERS / VIEWS ENGINE

Контекст

В предыдущих этапах реализованы:

- Workspace;
- Projects;
- Project Items;
- Production;
- Tasks;
- Documents;
- Dashboard Engine;
- Plug & Play Widgets;
- Calendar & Events;
- Excel / CSV Import & Export;
- Google Sheets Import / Export.

Теперь необходимо реализовать универсальный Search / Filters / Views Engine.

Главная идея:

«Пользователь не должен каждый раз вручную настраивать таблицу заново.»

Он должен иметь возможность создать своё представление:

Мои проекты
→ Риск: высокий
→ Дедлайн: ближайшие 7 дней
→ Этап: производство
→ Сортировка: дедлайн ↑
→ Колонки: выбранные

и сохранить это как:

"Срочное производство"

После этого оно появляется как отдельный View.

36. Backend Query Builder

Не принимать frontend SQL.

Frontend отправляет безопасную структуру:

{
  "filters": {
    "operator": "AND",
    "conditions": [
      {
        "field": "risk_level",
        "operator": "in",
        "value": ["HIGH", "CRITICAL"]
      }
    ]
  }
}

Backend преобразует это в parameterized query.

frontend → raw SQL

Никогда:

Никогда:

без whitelist.

Все поля и операторы должны проходить validation.
