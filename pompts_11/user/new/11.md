PROMPT 12 — COMMENTS / DISCUSSIONS / MENTIONS

Контекст

В предыдущем этапе реализован единый Event / Activity / Audit Engine.

Теперь необходимо реализовать полноценную систему рабочих обсуждений внутри приложения.

Главная идея:

«Пользователю не нужно уходить в Telegram, WhatsApp или почту, чтобы обсудить проект. Контекст общения должен находиться непосредственно внутри проекта, задачи, документа или конкретной позиции заказа.»

Система должна поддерживать:

- комментарии;
- ответы;
- треды;
- упоминания пользователей;
- редактирование;
- удаление;
- вложения;
- ссылки на сущности;
- реакции;
- уведомления;
- Activity;
- права доступа.

ГЛАВНЫЙ ПРИНЦИП

Это не попытка сделать ещё один Telegram/Slack.

Это:

«Контекстное обсуждение вокруг работы.»

Правильная модель:

PROJECT
   │
   ├── DATA
   ├── ITEMS
   ├── TASKS
   ├── DOCUMENTS
   ├── FILES
   ├── ACTIVITY
   └── DISCUSSION
             │
             ├── comments
             ├── replies
             ├── mentions
             └── reactions

И всё это должно быть связано через единый:

EVENT ENGINE

а не через набор разрозненных механизмов.
