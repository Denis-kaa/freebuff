Твоя задача — провести глубокий технический аудит кодовой базы проекта (ai-dubber), проверить механику работы фоновых задач, подобрать оптимальные облачные GPU-серверы и составить подробный отчет для заказчика.

Выполни задачу строго по 4 пунктам:

1. Анализ кода и механики воркеров (Celery + Redis):
- Проанализируй файлы backend/workers/celery_app.py, backend/workers/tasks.py, backend/services/downloader.py, synthesizer.py, merger.py и конфигурацию docker-compose.yml.
- Опиши точную схему: как воркер забирает задачу из очереди, какой уровень параллелизма (concurrency) сейчас настроен, как работают Redis-блокировки и rate limiter.
- Объясни, что физически происходит в системе при одновременной отправке 5–10 видео: сколько задач берутся в работу, сколько висят в Redis-очереди, где возникает узкое горлышко по CPU и RAM (транскрипция Whisper, склейка FFmpeg).

2. Подбор GPU-серверов и расчет стоимости:
- Заказчик использует AWS. Найди и рассчитай стоимость подходящих GPU-инстансов в AWS EC2 для инференса Whisper и рендеринга (например, g4dn.xlarge с NVIDIA T4 или g5.xlarge с NVIDIA A10G). Укажи стоимость в час и примерную стоимость в месяц при режиме 24/7.
- Найди 2-3 более дешевые альтернативы среди специализированных GPU-облаков (например, RunPod, Hetzner с GPU, Vast.ai или Modal) для сравнения бюджета.

3. Оптимальная архитектура продакшена:
- Предложи схему разделения: легкий сервер под FastAPI + Redis + Web (CPU) и отдельный подключаемый воркер с GPU под тяжелые задачи.
- Опиши, как правильно масштабировать воркеры под нагрузку без риска уронить базу данных и API.

4. Подготовка сообщения для заказчика:
- На основе собранных данных напиши понятный, развернутый и убедительный текст для заказчика (Лочинбека).
- Без сложного жаргона объясни ему: как сейчас распределяется очередь, почему обработка на CPU занимает время, какие серверы (с ценами в долларах/рублях) ему нужно арендовать для быстрой работы, и какой пошаговый план внедрения GPU мы предлагаем как отдельный этап.

Выведи подробный технический отчет по всем пунктам.
