3. ЭТАП 1 — ПРОВЕРКА СЕРВЕРА
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Сначала подключись по SSH.

НЕ устанавливай ничего сразу.

Проверь:

1. Пользователя:

whoami

2. ОС:

cat /etc/os-release

3. Версию ядра:

uname -a

4. IP-адреса:

ip addr

5. Свободное место:

df -h

6. Состояние UFW:

ufw status

7. Состояние SSH:

systemctl status ssh --no-pager

8. Проверить, занят ли порт 2053:

ss -lntp | grep ':2053'

9. Проверить, установлен ли уже x-ui:

which x-ui

10. Проверить существующий сервис:

systemctl status x-ui --no-pager

11. Проверить наличие существующей установки:

ls -la /usr/local/x-ui 2>/dev/null


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
4. ПРОВЕРКА РЕЗУЛЬТАТОВ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Если:

- это не Ubuntu;
- пользователь не root;
- SSH работает некорректно;
- порт 2053 уже занят неизвестным сервисом;
- уже установлен x-ui/3x-ui;
- обнаружена потенциально конфликтующая установка;

НЕ продолжай автоматически.

Сначала сообщи мне результаты проверки.

Если x-ui уже установлен и работает —
НЕ устанавливай его повторно.

В этом случае проверь существующую установку и сообщи её состояние.

6. ОТВЕТЫ УСТАНОВЩИКУ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

При установке необходимо настроить панель следующим образом:

ПОРТ ПАНЕЛИ:

2053

Если установщик спрашивает:

"Enter panel port"

или аналогичный вопрос —
оставить значение по умолчанию 2053, нажав Enter.

SSL:

НЕ использовать.

Если установщик спрашивает об установке SSL,
сертификате, HTTPS или домене:

выбрать NO / n.

Причина:
leviathanstory.ru пока не резолвится в IP.

ВАЖНО:

Не нажимай Enter механически на ВСЕ вопросы.

Каждый вопрос установщика необходимо распознать.

Если вопрос соответствует настройкам выше —
выбрать указанное значение.

Если появляется неожиданный вопрос, который может:

- изменить существующие настройки;
- удалить данные;
- изменить SSH;
- изменить firewall;
- переустановить компонент;
- изменить сетевую конфигурацию;

ОСТАНОВИСЬ и сообщи мне полный текст вопроса.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
7. FIREWALL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

После успешной установки проверь UFW:

ufw status

Перед изменением firewall убедись,
что SSH-доступ разрешён.

Только после этого открыть TCP-порт панели:

ufw allow 2053/tcp

НЕ выполнять:

ufw reset

НЕ удалять существующие правила firewall.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
8. ПЕРЕЗАПУСК
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

После установки выполнить:

x-ui restart

Затем проверить:

x-ui status

и:

systemctl status x-ui --no-pager


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
9. ПРОВЕРКА ПОРТА
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Проверить:

ss -lntp | grep ':2053'

Убедиться, что x-ui действительно слушает:

0.0.0.0:2053

или эквивалентный адрес.

Также проверить локальный HTTP-ответ:

curl -I http://127.0.0.1:2053
