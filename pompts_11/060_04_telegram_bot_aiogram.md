Разработка Telegram-бота 

О проекте

Ищу разработчика для создания Telegram-бота  с нуля. Это будет маркетплейс цифровых товаров (Roblox, Steam, подарочные карты и другие цифровые товары).

Что нужно сделать

Необходимо разработать проект полностью с нуля:

* Создать архитектуру проекта.
* Разработать Telegram-бота.
* Сделать удобное главное меню.
* Реализовать каталог товаров.
* Личный кабинет пользователя.
* Систему оформления и оплаты заказов.
* Историю заказов.
* Панель администратора.
* Кабинет продавца.
* Автоматическую выдачу цифровых товаров после оплаты.
* Уведомления пользователям и администраторам.
* Подключить базу данных.
* Подключить платежную систему.
* Подготовить проект к дальнейшему развитию.

Технологии

Предпочтительно:

* Python
* aiogram 3.x
* PostgreSQL или SQLite
* Git

Если вы считаете, что для проекта лучше использовать другие технологии, готов обсудить.

Требования

* Опыт разработки Telegram-ботов.
* Умение самостоятельно проектировать структуру проекта.
* Чистый и понятный код.
* Ответственный подход к работе.
* Желателен опыт с платежными системами и маркетплейсами.

Формат сотрудничества

Ищу разработчика для долгосрочного сотрудничества. После запуска планируется развитие проекта и добавление новых функций.
