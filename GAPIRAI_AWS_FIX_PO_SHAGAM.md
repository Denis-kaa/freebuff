# Исправление входа на gapirai.uz — шаг за шагом

**Проблема:** вход и регистрация возвращают ошибку 404. Это происходит на любом компьютере — проблема не в Mac. Сервер не перенаправляет адреса входа (`/auth/...`) на API.

**Необходимое время:** около 10 минут.

---

## Шаг 1 — Подключиться к серверу

В Терминале (Mac) или PowerShell (Windows):

```bash
ssh ubuntu@ВАШ_IP_AWS
```

> Используйте тот же IP и пользователя, что и при доступе к серверу. Если вы подключаетесь другим способом (например, через панель AWS) — можно использовать его.

---

## Шаг 2 — Узнать имя конфигурационного файла

```bash
ls /etc/nginx/sites-enabled/
```

Появится список (например: `ai-dubber`, `gapirai`, `default`). Запомните имя файла, относящегося к сайту. В следующих шагах вместо `ИМЯ-ФАЙЛА` подставляйте это имя.

---

## Шаг 3 — Сделать резервную копию

```bash
sudo cp /etc/nginx/sites-enabled/ИМЯ-ФАЙЛА /etc/nginx/sites-enabled/ИМЯ-ФАЙЛА.bak
```

---

## Шаг 4 — Открыть файл для редактирования

```bash
sudo nano /etc/nginx/sites-enabled/ИМЯ-ФАЙЛА
```

---

## Шаг 5 — Найти блок `/api/`

В редакторе нажмите **Ctrl+W**, введите `location /api/` и нажмите Enter. Вы увидите примерно это:

```nginx
location /api/ {
    proxy_pass http://127.0.0.1:8000;
    ...
}
```

---

## Шаг 6 — Вставить новый блок сразу ПОД блоком `/api/`

После закрывающей скобки `}` блока `/api/` вставьте точно следующее:

```nginx
location /auth/ {
    proxy_pass http://127.0.0.1:8000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
}
```

Сохранить: **Ctrl+O**, Enter. Выйти: **Ctrl+X**.

---

## Шаг 7 — Проверить и применить

```bash
sudo nginx -t
```

Если появилось `syntax is ok` / `test is successful`, примените:

```bash
sudo systemctl reload nginx
```

Если `nginx -t` показывает ошибку — повторите Шаг 6, проверив, что текст вставлен точно как выше (точки с запятой и скобки).

---

## Шаг 8 — Проверить результат

```bash
curl -X POST https://gapirai.uz/auth/login -H "Content-Type: application/json" -d '{"email":"test@test.com","password":"x"}'
```

**Правильно:** короткий JSON-ответ (например `{"detail":"Bu email..."}`).
**Неправильно:** большая HTML-страница с «404».

Затем проверьте в браузере: `https://gapirai.uz/login` → введите email и пароль → сайт должен показать сообщение (например «email не зарегистрирован»), а не ошибку 404.
