## 📋 Техническое задание (ТЗ)

### Цель
Интегрировать freebuff с двумя внешними компонентами экосистемы:
1. Локальный терминальный агент `termux-ai-agent` — для сохранения его диалогов в freebuff ContextManager.
2. Headless-браузер Lightpanda — для веб-автоматизации из freebuff.

### Функциональные требования (MUST)
- [x***REMOVED*** `AgentContextBridge` — Python-мост между `termux-ai-agent` и `ContextManager`.
- [x***REMOVED*** `termux-ai-agent/main.py` логирует user/assistant/system сообщения в freebuff.
- [x***REMOVED*** Авточекпоинт каждые 10 сообщений.
- [x***REMOVED*** CLI `--freebuff-conspect` для ручного конспекта.
- [x***REMOVED*** `LightpandaWorker` с методами: `execute_agent_task`, `run_script`, `dump_url`, `serve_cdp`, `stop_cdp`.
- [x***REMOVED*** `scripts/install_lightpanda.sh` для Termux + proot-distro Ubuntu ARM64.
- [x***REMOVED*** Документация: `docs/LIGHTPANDA_INTEGRATION.md`, `docs/WORKERS.md`, `docs/ARCHITECTURE.md`.
- [x***REMOVED*** Unit-тесты для `AgentContextBridge` и `LightpandaWorker`.
- [x***REMOVED*** `mypy` и `pytest` — 0 ошибок.

### Ограничения
- Termux на Android (ARM64)
- Python 3.11+
- Lightpanda требует glibc → запуск через proot-distro Ubuntu
- Интеграция опциональная, не должна ломать termux-ai-agent при отсутствии freebuff
