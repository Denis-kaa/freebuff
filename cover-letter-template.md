## Блок «Кейсы» — вставлять по 1–2 в письмо

**Кейс A — автоматизация фриланс-заказов (kwork-cli)**
> Сделал инструмент, который сам читает техническое задание, разбивает его на задачи, пишет код и тестирует результат. Раньше на заказ уходило 10–20 часов, сейчас 30–40 минут моего контроля. Использую каждый день.

**Кейс B — собственная AI-платформа (Freebuff)**
> Построил платформу, которая связывает разные AI-модели и агентов: роутер сам подбирает модель под задачу, 5 уровней памяти, RAG, MCP-сервер, Telegram-бот. 3350+ автоматических тестов, 0 failures. Архитектура: контракты, ADR, аддитивные изменения.

**Кейс C — мультиагентные дебаты (Leviathan Engine)**
> Собрал систему, где три AI-агента ведут дебаты и принимают решения. Столкнулся с проблемой: модели начали поддакивать друг другу вместо независимого анализа. Пересобрал архитектуру: перекрёстная проверка, протокол обязательного цитирования источников, валидация выводов. Теперь система выдаёт проверяемые ответы.

**Кейс D — reverse-engineering Excel/VBA → Python (ВкусВилл)**
> Собрал модельный пример: Excel-файл с логикой прогноза спроса и автозаказа (включая скоропортящуюся категорию с поправкой на срок годности). Перенёс логику в Python с понятными именами вместо магических коэффициентов и проверил, что новая версия считает так же, как оригинал. На этом шаге нашёл ошибку: первая проверка сравнивала мой же код сам с собой, а не с настоящими Excel-формулами. Переделал проверку — совпадение точное.

**Кейс E — стабилизация продакшена (GapirAI.uz) ⚠️ с разрешения клиента**
> Аудит и стабилизация production-сервиса автодубляжа видео (FastAPI + Celery + PostgreSQL + Redis + TTS). Устранены 5 корневых причин деградации: OOM-краши (перенос склейки в ffmpeg), циклические рестарты (Redis NX-локи), отваливающиеся куки. Итог: 0 ошибок на контрольном прогоне.

**Кейс G — автономный DevOps-агент (Leviathan_Agent)**

5. **Проверять факты перед отправкой**: даты, цифры, названия.
