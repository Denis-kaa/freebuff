# tg-terminal-toolkit

Терминальный Telegram-клиент с TUI для Android (Termux).

## Быстрый старт

```bash
cd projects/tg_terminal_messenger/
pip install -r requirements.txt
python src/main.py
```

## Команды

| Клавиша | Действие |
|---------|----------|
| Tab | Переключение панелей (чаты ↔ сообщения) |
| Ctrl+F | FilePicker (отправка файла) |
| Ctrl+D | Скачать медиа чата |
| Ctrl+Q | Выход |
