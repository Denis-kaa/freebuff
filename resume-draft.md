### Самозанятый · Независимый AI-разработчик
**2025 — настоящее время** · удалённо

Разрабатываю AI-инструменты и автоматизацию для решения бизнес-задач: от идеи до работающего продукта.

**Ключевые результаты:**

1. **kwork-cli — автоматизация фриланс-заказов** (использую ежедневно)
   Инструмент читает техническое задание, разбивает его на задачи, пишет код и тестирует результат.
   - ✅ Экономия времени: **10–20 часов → 30–40 минут** контроля на заказ

2. **Freebuff / Workspace OS — собственная AI-инженерная платформа**
   Полноценная платформа для управления AI-проектами: менеджер контекста, 5 уровней памяти, knowledge-движок, роутер моделей по capabilities, event bus, оркестратор, MCP-сервер, Telegram-бот.
   - ✅ **3350+ автоматических тестов**, 0 failures
   - ✅ Архитектура: контракты, ADR, документация, аддитивные изменения

3. **Telegram-бот «Пухляш» — персональный ассистент по питанию** (использую ежедневно)
   Бот с характером: трекер веса, список покупок, рецепты из холодильника, дайджесты дня/недели, ротация до 5 ключей Gemini, SQLite+WAL.
   - ✅ Production, **есть активные пользователи**

4. **Orionyx — инвестиционная платформа** ⚠️ (упоминать только с разрешения клиента)
   FastAPI-платформа с аналитикой портфеля, личным кабинетом, отчётами и обработкой произвольных CSV/XLSX-выгрузок.

5. **Leviathan Engine — мультиагентная платформа**
   Система, где три AI-агента ведут дебаты и принимают решения. Решил проблему «модели поддакивают друг другу»: перекрёстная проверка, обязательное цитирование источников, валидация выводов.
   - ✅ Проверяемые ответы вместо «красивого текста»

6. **HR-Agent — автономный карьерный агент** (использую периодически)
   FastAPI + 8 модулей + Telegram-бот + SQLite + HH.ru API: сам ищет вакансии, оценивает шансы, анализирует требования, готовит отклики.
