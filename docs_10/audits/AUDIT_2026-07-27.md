## 🧰 Созданные инструменты

| Инструмент | Файл | Назначение |
|------------|------|------------|
| **Scanner** | `scripts_01/scanner.py` | Поиск инструментов по 12 категориям паттернов |
| **KeyPool** | `.keys/keypool.py` | Пул ключей: ротация (round-robin + random) + валидация |
| **Key Files** | `.keys/*.keys` | Файлы ключей по провайдерам (6 файлов, 26 ключей) |
| **Key State** | `.keys/state.json` | Кеш состояния (результаты валидации, usage_count) |

### Как пользоваться

```bash
cd /storage/emulated/0/PROJECTS/workstation/freebuff/

# Скан системы
python scripts_01/scanner.py

# Статус ключей
python .keys/keypool.py status

# Валидировать все ключи
python .keys/keypool.py validate

# Валидировать конкретный провайдер
python .keys/keypool.py validate deepseek

# Получить следующий ключ (round-robin)
python .keys/keypool.py rotate gemini

# Импорт из .env и Qwen
python .keys/keypool.py import
```

### Интеграция в код

```python
import sys
sys.path.insert(0, "/storage/emulated/0/PROJECTS/workstation/freebuff")
from keys.keypool import KeyPool

pool = KeyPool()

# Round-robin (LEVIATHAN-стиль)
key = pool.rotate("gemini")

# Случайный
key = pool.random("deepseek")

# Лучший (минимальный usage_count среди валидных)
key = pool.best("sambanova")
```
