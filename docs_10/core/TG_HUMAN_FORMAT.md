# Telegram-формат для внешних получателей — человеческим языком

**Когда применяется:**
- Сообщения в «Избранное» (Telegram Saved Messages `7709651193`) — личная копилка
- Сообщения клиенту (Александр Литвинов `1063827731`) — заказчик

## Структура

```
✅ Что сделали (1-3 пунктов):
— Пункт-1 простым языком (что это ЗНАЧИТ для проекта)
— Пункт-2 простым языком

⏭️ Что осталось:
— Шаг X из Y (что нужно ещё сделать)

📊 Прогресс: A из B шагов готовы.
```

## Запрещено

- Технические ID: `Block-A`, `CON-17`, `CAN-8`, `CAN-9`, `ANTI-10`, `ANTI-11`
- Stack trace, имена exception-классов (`ModuleNotFoundError`, `IndentationError`)
- Версии в строгом формате `v5.51.0` — допустимо «сегодня», «только что»
- Абстрактные существительные: «двухслойный verify gate», «архитектурная реструктуризация»

## Разрешено

- Конкретные действия: «перенесли файлы», «починили импорт», «запустили тест»
- Числа прогресса: «6 из 10», «осталось 2 долга»
- Прямые обращения: «Вот что в итоге», «Что дальше»
- Краткие оценки: «готово», «в работе», «заблокировано»

## Пример

### ❌ Плохо (технический формат)
```
v5.51.0 Ship ✅
- 2 scripts moved (e2e_promt47.py, interior_consultant_register.py) → /storage/.../interior_planner_e2e/
- Block-A sys.path injection fixed (shared _freebuff_locator.py, drop walk-up per CON-17)
- 3 NEW debt: CAN-8 body-level hardcodes, CAN-9 real-client verify, ANTI-11 surgical-vs-holistic
- py_compile exit 0, Gate-1 sys_inj PASS both
```

### ✅ Хорошо (формат для людей)
```
✅ Что сделали:
— Два скрипта переехали в свой проект (раньше они лежали в общей папке и путались с другими).
— Один из скриптов перестал падать при запуске (починил пути импорта).

⏭️ Что осталось из 7 шагов:
— Прогнать всё «по-настоящему» (с реальным Telegram, не тестовый режим)
— Поправить три мелочи внутри скриптов

📊 Прогресс: 5 из 7 шагов готовы.
```

## Применение

Все TG-сообщения на исходящую ДОЛЖНЫ следовать этому формату.
Технические детали — в `CHANGELOG.md` + `ARCHITECTURAL_DEBT.md` (внутренние артефакты).
