# Сценарий: Telegram бот  

## Описание задачи

Разработка Telegram бота на Python для автоматизации задач.
Бот может быть: информационный, уведомления, заказ услуг, администрирование.

## Технические требования

```yaml
стек:
  python: 3.11+
  библиотеки:
    - python-telegram-bot 20.x  # Bot API
    - aiohttp  # HTTP для внешних API
    - pydantic  # модели данных
  хранение: sqlite (через sqlite3/aiosqlite)
  деплой: VPS / Termux
```
