# Сценарий: SEO аудитор  \n

## Описание задачи

Разработка инструмента для SEO аудита веб-сайтов: анализ мета-тегов, скорости загрузки, структуры URL,
внутренних/внешних ссылок, заголовков, контента. Результат — детальный отчёт с рекомендациями.

## Технические требования

```yaml
стек:
  python: 3.11+
  библиотеки:
    - requests/aiohttp  # HTTP клиент
    - beautifulsoup4/lxml  # HTML парсинг
    - pydantic  # модели
    - openpyxl  # Excel отчёты
    - jinja2  # HTML шаблоны отчётов
    - playwright  # JavaScript рендеринг (опционально)
  вывод: json | html | excel | pdf
```
