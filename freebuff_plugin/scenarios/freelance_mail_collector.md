# Сценарий: Сборщик почты  \n

## Описание задачи

Разработка сборщика писем из почтовых ящиков через IMAP протокол.
Парсит письма, извлекает вложения, структурирует данные, сохраняет в базу.

## Технические требования

```yaml
стек:
  python: 3.11+
  библиотеки:
    - imaplib  # IMAP протокол (встроенная)
    - email  # парсинг писем (встроенная)
    - pydantic  # модели
    - sqlalchemy  # БД
    - beautifulsoup4  # очистка HTML
  хранение: sqlite | postgresql
  вывод: json | csv | база
```
