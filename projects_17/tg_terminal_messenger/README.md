# tg-terminal-toolkit

Терминальный Telegram-клиент с TUI для Android (Termux).

## Быстрый старт

```bash
cd projects_17/tg_terminal_messenger/
pip install -r requirements.txt
python src/main.py
```

> Если приложение пишет `❌ database is locked` — где-то висит другой экземпляр:
> `ps aux | grep main.py` → `kill <PID>`, затем `rm -f tg_session.session-journal`.
> Если `⚠️ Нужна авторизация` — сначала один раз: `python test_tg.py` (введёшь код из Telegram).

## 🕓 Офлайн-история и быстрая загрузка

- Диалоги и сообщения кэшируются в `tg_cache.db` (SQLite, WAL) рядом с проектом.
- **Открытие чата не ждёт сеть:** сначала мгновенно показывается кэш,
  затем в фоне подтягиваются свежие сообщения из Telegram. Сетевой сбой при
  открытом кэше — просто «кэш показан», без ошибки.
- **Без сети** список чатов и переписка открываются из кэша: уведомления
  «🕓 Офлайн: показаны кэшированные чаты» / «🕓 Офлайн-история из кэша».
- Отправка сообщений и файлов офлайн блокируется с понятным предупреждением.
- Реализация: `aiosqlite`, если установлен, иначе — stdlib `sqlite3`
  (зависимость не обязательна).

## ⚙️ Настройки (`settings.json`)

Рядом с проектом лежит `settings.json` (создаётся автоматически с дефолтами):

```json
{
  "history_limit": 30,
  "mode": "advance",
  "cache_cap": 200,
  "cache_days": 30
***REMOVED***
```

- `history_limit` — сколько сообщений показывать при открытии чата.
  Дефолт 30; поставь 100–200, если нужна глубокая история сразу.
- `mode` — `"advance"` (все функции, дефолт) или `"light"` (чисто переписка).
- `cache_cap` — максимум сообщений на чат в кэше (и лимит автоподгрузки).
  Дефолт 200. **Защита от «тащит всю историю»**: раньше автоподгрузка каскадом
  по 30 сообщений каждые 0.4 с вытягивала весь кэш/всю историю Telegram, пока
  ты на верху чата — теперь она останавливается на `cache_cap`, а старее
  подгружаются только явным скроллом вверх (↑/j/k/PageUp). Самые старые
  сообщения сверх лимита удаляются из кэша при сохранении.
- `cache_days` — срок хранения кэша в днях (дефолт 30). При **старте**
  приложения сообщения старше `cache_days` дней удаляются из `tg_cache.db`
  (с уведомлением «🧹 Кэш: удалено N сообщений»). Второй лимит поверх
  `cache_cap`: лимит на количество на чат + лимит по возрасту — старые
  записи не копятся даже в чатах, куда давно не заходили. `0` — отключить.

## 🔀 Режимы: лайт / адванс

- **Лайт** (`light`) — чисто переписка: сообщения + строка ввода.
  Скрываются поиск по сообщениям, кнопки 🎤 Голос / 🎬 Видео / 🎞 GIF и отправка файлов.
- **Адванс** (`advance`) — все функции: поиск, голосовые, видео, GIF, файлы, медиа, масштаб.
- Переключение на лету — **Ctrl+G** (или вручную в `settings.json`,
  режим применяется при открытии чата).

## 🔍 Поиск в чате и подгрузка истории

- **Ctrl+F внутри чата** — поиск по сообщениям (фильтрует живьём, подсветка совпадений;
  Enter — перейти в список, Esc — закрыть). Работает и по кэшированным сообщениям офлайн.
- **Скролл вверх до самого верха (↑/j/k/PageUp)** — подгружает более старые
  сообщения: из сети, а офлайн — из кэша. Автоподгрузка останавливается на
  `cache_cap` (по умолчанию 200) с тостом «⏹ Кэш: 200 сообщений…»; дальше —
  только повторным скроллом вверх. Уведомление «🏁 Дошли до начала истории»
  означает, что история закончилась.

## ⌨️ Стрелки в Termux

На Android-клавиатуре стрелок нет — включи **extra keys** в Termux:

- Нажми **Volume-Up** (или зажми клавишу клавиатуры → «Show extra keys») —
  появится ряд `ESC TAB CTRL ALT ← ↑ → ↓`, стрелки там.
- Или пропиши в `~/.termux/termux.properties`:
  ```
  extra-keys = [['ESC','/','-','HOME','UP','END','PGUP'***REMOVED***,['TAB','CTRL','ALT','LEFT','DOWN','RIGHT','PGDN'***REMOVED******REMOVED***
  ```
  затем выполни `termux-reload-settings`.
- Запасной вариант прямо в TUI: **j / k** — вниз/вверх по списку (работает всегда,
  без стрелок).

## 📎 Медиа: просмотр и отправка

- **Отправить файл** — в чате нажми **Ctrl+O** или просто **a**:
  - Если установлен системный пикер (`pkg install termux-api`), откроется выбор файла Android
    (бинарь **`termux-storage-get`**; бинаря `termux-file-picker` в termux-api не существует).
  - **Без него** откроется **встроенный браузер прямо в терминале**:
    `j/k` — вниз/вверх, `Enter` — войти в папку / выбрать файл, `h` — на уровень выше,
    `Esc` — отмена, первый пункт — ввести путь вручную.
    **Быстрый переход в избранные папки одной клавишей:**
    `d` — Загрузки, `i` — Картинки, `c` — DCIM, `m` — Музыка (прыгает в `~/storage/<папка>`;
    если папки нет — подсказка сделать `termux-setup-storage`).
    Стартовая папка — `~/storage` (downloads/dcim/pictures/music, после `termux-setup-storage`).
  - **Кнопка 🎤 Голос в строке ввода чата** — голосовое сообщение двумя способами:
    - **Запись** (если установлен `pkg install termux-api`): первый клик — начать запись
      (`termux-microphone-recorder`, файл `voice_*.m4a` в папке медиа), **второй клик — стоп**.
      После стопа — **выбор, что делать с записью**:
      - **📤 Отправить** (`s`/Enter) — как голосовое (`voice_note`, в Telegram — синяя волна, не файл);
      - **▶️ Прослушать** (`p`/`l`) — запись играет прямо из терминала
        (`termux-media-player`; без него — системный плеер через `termux-open`),
        экран выбора остаётся открытым;
      - **🗑 Удалить** (`d`/Esc) — файл удаляется.
      **Esc** во время записи — отменить её (процесс убивается, файл удаляется).
      Кнопка при записи меняется на ⏹ с **живым счётчиком секунд** (мм:сс).
      Выход из чата во время записи тоже отменяет её.
    - **Выбор аудиофайла** (если `termux-api` нет): открывается системный пикер или
      встроенный браузер в режиме audio (только `🎵` аудио: `.mp3/.ogg/.opus/.m4a/.wav/...`
      по расширению **или магии** — SAF-копия `.bin` распознаётся по содержимому);
      выбранный файл отправляется как голосовое сообщение.
  - **Кнопка 🎞 GIF в строке ввода чата** — отправить гифку из галереи одной кнопкой:
    открывается системный пикер (или браузер в режиме GIF — только `.gif/.webp`),
    файл проверяется, что это реально **анимированный** `.gif`/`.webp` (PIL, >1 кадра;
    анимированный webp уходит как гифка — `DocumentAttributeAnimated`).
    **Перед отправкой показывается превью первого кадра прямо в терминале**
    (chafa, ANSI-арт): `y`/`Enter` — отправить, `n`/`Esc` — отмена. Не-анимация
    (статичный gif/webp, jpg, mp4) отклоняется с предупреждением.
  - **Кнопка 🎬 Видео в строке ввода чата** — съёмка с камеры ИЛИ выбор видеофайла:
    - **Камера** (если установлен `pkg install termux-api`): клик открывает камеру
      (`termux-camera-photo`, делается **фото**, файл `foto_*.jpg` в папке медиа);
      после съёмки — превью в терминале + подтверждение: `y`/`Enter` — отправить,
      `n`/`Esc` — отмена. Видео-запись termux-api не умеет — только фото.
    - **Выбор видеофайла** (если `termux-api` нет): системный пикер или браузер
      в режиме видео (только `.mp4/.mkv/.webm/.avi/.mov/.3gp/...`); не-видео
      отклоняется с предупреждением.
  - Тип определяется по расширению: `.jpg/.png` → фото, `.mp4` → видео, `.gif` → гифка,
    `.mp3` → музыка.
- **Посмотреть медиа из переписки** — выбери сообщение с меткой (📷 Фото, 🎬 Видео,
  🎞 GIF, 🎵 Музыка, 🎤 Голосовое) и нажми **Enter**: файл скачается.
  - **Картинки/гифки** показываются **прямо в терминале** ANSI-артом через `chafa`
    (установка: `pkg install chafa`; закрыть превью — `Esc`/`Enter`/`q`).
    **Анимированные GIF/WebP проигрываются кадр за кадром** (chafa `--animate on`,
    таймер Textual; если chafa не разделяет кадры — fallback через PIL).
    Пауза/продолжение — **`p`**, внизу видно число кадров.
  - **Масштаб превью** — в превью нажми **`+`** (или `=`) — увеличить,
    **`-`** (или `_`) — уменьшить, **`0`** — сброс к 100%: chafa перезапускается
    с новым размером (для анимации кадры пересобираются, таймер перезапускается).
  - **Видео** — показывается **первый кадр** (извлекается через `ffmpeg`,
    установка: `pkg install ffmpeg`) ANSI-артом через `chafa`; в превью нажми
    **`o`**, чтобы открыть оригинал в системном плеере (`termux-open`).
  - **Музыка/документы** открываются системным просмотрщиком (`termux-open`),
    либо так же, если chafa не установлен.
- **Повторный просмотр без скачивания** — в чате нажми **`v`**: уже скачанный файл
  из папки `~/storage/downloads/tg_terminal/` откроется сразу (превью в терминале,
  если chafa есть, иначе системный просмотрщик). Если файла нет на диске —
  уведомление «Файл не скачан» (тогда сначала Enter на сообщении).
- Файлы сохраняются в `~/storage/downloads/tg_terminal/` — видно в Files/Галерее.
  Если папки `~/storage` нет — один раз выполни `termux-setup-storage`
  (выдаст доступ к общему хранилищу Android).
- **В чате стрелки ↑/↓ работают даже при фокусе на строке ввода** — двигают
  выбор по сообщениям (Enter откроет выделенное медиа).

> **Совет:** чтобы видеть `~/storage` (downloads/dcim/pictures) в браузере файлов,
> один раз выполни в Termux `termux-setup-storage` и перезапусти приложение.

## Команды

| Клавиша | Действие |
|---------|----------|
| ↑/↓ | Навигация по списку чатов |
| Enter | Открыть выбранный чат |
| Esc | Назад к списку чатов / закрыть поиск |
| Ctrl+F | Поиск по чатам |
| Ctrl+G | Переключить режим: лайт / адванс |
| Ctrl+T | Фокус на строку ввода (в режиме чата) |
| Ctrl+O / a | Отправить файл/медиа (📎) |
| 📎 Файл (кнопка) | Отправить файл: системный пикер / встроенный браузер (то же, что Ctrl+O) |
| 🎤 Голос (кнопка) | Голосовое: клик — запись, клик — стоп; затем отправить (s) / прослушать (p) / удалить (d). Без termux-api — выбор аудиофайла. Esc во время записи — отмена |
| 🎬 Видео (кнопка) | Камера (📸 фото через termux-camera-photo + превью/подтверждение) или выбор видеофайла (пикер/браузер) |
| 🎞 GIF (кнопка) | Отправить анимированный `.gif`/`.webp` из галереи: превью первого кадра (chafa) + `y`/`Enter` — отправить, `n`/`Esc` — отмена |
| v | Открыть скачанное медиа без повторного скачивания |
| o | В превью видео: открыть оригинал в плеере |
| + / − / 0 | В превью: увеличить / уменьшить / сбросить масштаб |
| Ctrl+E | Добавить/убрать чат из избранного |
| Ctrl+R | Обновить диалоги |
| Ctrl+X / Ctrl+Q | Выход |
| Tab | Переключить фокус: список сообщений → 📎 Файл → 🎤 Голос → 🎬 Видео → 🎞 GIF → строка ввода |
| j / k | Навигация по списку (без стрелок) |
| h (в браузере файлов) | На уровень выше |
| d / i / c / m (в браузере файлов) | Быстрый переход: Загрузки / Картинки / DCIM / Музыка |

> **Примечание:** Ctrl+I НЕ работает как клавиша — в терминале Ctrl+I совпадает с Tab.
> Для фокуса на ввод используй Ctrl+T. В Termux зажми клавишу `CTRL` в верхнем ряду
> «extra keys» (или Volume-Down) и нажми нужную букву.
