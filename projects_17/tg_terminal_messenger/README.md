# tg-terminal-toolkit

Терминальный Telegram-клиент с TUI для Android (Termux).

## Быстрый старт

```bash
cd projects/tg_terminal_messenger/
pip install -r requirements.txt
python src/main.py
```

## Команды

| Клавиша | Действие |
|---------|----------|
| ↑/↓ | Навигация по списку чатов |
| Enter | Открыть выбранный чат |
| Esc | Назад к списку чатов / закрыть поиск |
| Ctrl+F | Поиск по чатам |
| Ctrl+I | Фокус на строку ввода (в режиме чата) |
| Ctrl+E | Добавить/убрать чат из избранного |
| Ctrl+R | Обновить диалоги |
| Ctrl+X | Выход |

## Статус

🟡 MVP — чтение диалогов и отправка сообщений работают. Планируется: push-уведомления, multi-account, экспорт истории.
