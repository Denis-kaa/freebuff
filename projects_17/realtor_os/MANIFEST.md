# Паспорт проекта Realtor OS

| Поле | Значение |
|---|---|
| **Название** | Realtor OS |
| **Версия** | 0.1.0 |
| **Назначение** | Локальная автономная система автоматизации для риелтора |
| **Владелец** | Риелтор «Этажи», Пойковский |
| **Лицензия** | MIT |
| **Среда** | Termux на Android (ARM64) |
| **Требования к правам** | No-root |
| **Статус** | Foundation / production-ready v0.1 |

## Цели

1. Хранить локальную базу объектов и документов.
2. Шифровать персональные данные клиентов.
3. Распознавать документы OCR локально.
4. Отвечать на вопросы через локальную LLM + RAG.
5. Синхронизировать зашифрованные бэкапы с Яндекс Диском.
6. Пополнять базу знаний через `/learn`.

## Архитектура

- **Ядро безопасности** — GPG/OpenSSL обёртка, работа с PII.
- **RAG** — SQLite + FTS5/vec для локального поиска.
- **OCR** — Tesseract CLI.
- **LLM** — llama.cpp / Ollama через HTTP.
- **Интеграции** — Яндекс Диск (OAuth), Email (SMTP/IMAP).
- **Companion layer** — Buffy-совместимый `buffy_manifest.json` и `companion/state.json`.

## Контроль Buffy

Buffy может:
- читать `buffy_manifest.json` и `companion/state.json`;
- запускать `scripts/start_system.sh`;
- выполнять `realtor_os.cli` команды;
- проверять логи в `logs/realtor_os.log`.

Проект **не импортирует** `freebuff_plugin` и не зависит от экосистемы freebuff.
