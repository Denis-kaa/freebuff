3. ARCHITECTURAL BOUNDARIES

Эти границы обязательны.

Intelligence

Отвечает:

- WHAT?
- WHY?
- SHOULD WE?
- WHICH OPPORTUNITY?
- WHICH SCENARIO?

Intelligence НЕ выполняет Forge напрямую.

---

Opportunity

Opportunity — это не задача и не окончательное решение.

Это управляемая возможность проекта.

Минимальный lifecycle:

DISCOVERED
    ↓
ACTIVE
    ↓
READY
    ↓
COMPLETED

Также необходимо поддержать:

ACTIVE → DEFERRED
DEFERRED → ACTIVE

Критически важно:

«DEFERRED ≠ DELETED»

Если пользователь не выбрал Opportunity сейчас, она не должна исчезать.

Она может быть неактуальна сегодня, но стать актуальной позже.

---

Scenario

Scenario отвечает:

«HOW?»

Одна Opportunity может иметь несколько кандидатов Scenario.

Например:

Opportunity:
"Создать книгу"

Scenario A:
Research → Structure → Draft → Edit

Scenario B:
Research → Narrative → Chapters → Revision

Scenario C:
Knowledge → Concept → Draft → Editorial

Это НЕ три разные Opportunity.

Это три способа реализации одной Opportunity.

Intelligence может ранжировать Scenario candidates.

---

Factory

Factory отвечает за декларативное описание capability.

Factory:

- не принимает стратегические решения;
- не является Intelligence;
- не заменяет Scenario;
- не является Forge.

---

Forge

Forge — исполнительный производственный слой.

Использовать только существующий санкционированный путь:

ForgeFacade
    ↓
initiate_forge()
/ run_chain()
    ↓
ForgePipeline

ЗАПРЕЩЕНО создавать альтернативный прямой путь к Forge.

---

Agent

Agent — исполнительный участник.

Agent НЕ является:

- Intelligence;
- Factory;
- Scenario.

8. WHIM CAPTURE

Создай минимальный механизм фиксации Whim.

Whim — лёгкая входная единица:

"Что если..."
"Идея..."
"Наблюдение..."
"Надо проверить..."

Whim должен:

- иметь timestamp;
- иметь project context;

Минимальная модель должна быть простой.

Не создавай полноценную сложную Knowledge Ontology.

24. STOP CONDITIONS

- реальный repository противоречит критическому контракту;
- существующий Forge execution path невозможно безопасно использовать;
- требуется переписать production component;

- невозможно определить provenance данных.

НЕ обходи блокировку предположениями.
