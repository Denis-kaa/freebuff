# ADR-012 — G2: первый безусловный `allowed` источник = Open Data API «Работа в России» (SRC-012)

> **Статус:** ✅ Accepted (unconditional)
> **Дата:** 2026-08-23
> **Связано:** `SOURCE_POLICY_MATRIX.md` SRC-012, `ROADMAP.md` G2, `POST_MVP_GATES.md`, ADR-011 (первый conditional allowed — HeadHunter API)

## Контекст

G2 требует минимум один источник со статусом `allowed` для production-агрегации.

ADR-011 закрыл G2 условно: HeadHunter API (SRC-011) — официальный механизм, но
активация требует регистрации приложения, API-ключа и соблюдения условий
developer agreement. Осталась потребность в источнике, который:

- закрывает G2 **безусловно** (без credentials и активации);
- предоставляет официально разрешённый открытый механизм доступа;
- содержит релевантный контент — «кто-то ищет услугу/работу»;
- подтверждён живой проверкой, а не только документацией.

## Решение

**Первый безусловный `allowed` источник — Open Data API портала «Работа в России»
(ЕЦП trudvsem): `https://opendata.trudvsem.ru/api/v1/vacancies` (SRC-012).**

- Это **открытые данные** по официальному определению: «информация, которая
  находится в свободном доступе в сети Интернет для использования
  без ограничений» (`trudvsem.ru/opendata`).
- API реализован по «Методическим рекомендациям (Версия 3.0) по публикации
  открытых данных государственными органами».
- Доступ: публичный HTTP GET, **без ключей/авторизации**.
- Формат: JSON (контракт портала; не RSS/Atom — но это официальный открытый
  механизм, который G2 допускал как «RSS/Atom/API-источник»).
- Живая проверка 2026-08-23:
  - `GET /api/v1/vacancies?limit=2` → HTTP 200, `meta.total=513907`;
  - `GET /api/v1/vacancies?text=python&limit=1` → HTTP 200, 414 результатов.

## Ограничения/поля (G-SOURCE-3 — data minimization)

- Извлекаются: `id`, canonical URL вакансии, title, `creation-date`/`date_modify`,
  text (с TTL), регион/зарплата как опциональные;
- **не** извлекаются: резюме, соискатели, контакты, персональные данные
  (в API их нет в рамках «вакансии»);
- авторсьой базы нет: карточка ведёт только на исходный URL вакансии (attribution).

## Traffic / polling

- Пагинация: `offset/limit` (≤100/стр., ≤10 000/ответ);
- дельта-выборка: `modifiedFrom`/`modifiedTo` — идемпотентный checkpoint;
- polling floor — по здравому смыслу (не чаще необходимого; гос-портал);
- HTTPS, User-Agent идентифицирует продукт.

## Последствия

- G2 закрыт **полноправно и безусловно**: источник `allowed`, без credentials,
  с открытой лицензией — публичные pilot/P10 больше не блокируются активацией
  ключа (активация HH остаётся втрорым источником/дополнительным кандидатом).
- Live-код по-прежнему выключен до реализации адаптера и canary; источник не
  начинает работать «сам по себе» (гейт `allowed` + `can_poll`).
- RSS/Atom-семейство в матрице остаётся: SRC-001 (fixture), SRC-002
  (conditional), SRC-012 теперь `allowed`.

## Откат

Любое изменение правил портала (закрытие API, изменение лицензии) — источник
переводится в `manual_review`/`blocked` через реестр; live отключается без
изменения кода (гейт `can_poll`).
