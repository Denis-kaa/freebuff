# Fixtures — public_request_parser

Здесь будут храниться искусственные или лицензированно предоставленные тестовые RSS/Atom/Telegram-preview fixtures.

Правила:

- не добавлять реальные персональные данные;
- не добавлять приватные сообщения;
- не копировать полный контент живого источника без разрешённого основания;
- Telegram fixtures использовать только для проверки parser contract;
- для каждой fixture указывать происхождение, лицензию/основание, дату создания и ожидаемый результат.

На этапе scaffold каталог содержит только этот policy README.
