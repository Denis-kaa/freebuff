# LESSONS.md — Уроки проекта Model Dispatcher

> Формат: CON (подтверждено) / ANTI (анти-паттерн) / PB (процессный баг).
> Platform-тиражируемое — дополнительно в `core_02/LESSONS.md` (кросс-ссылка).

## CON-1 (2026-08-12): 90% «Диспетчера моделей» уже существовало в платформе

**Сценарий:** промт 81 просит «разработать модуль», но аудит показал, что
запуск freebuff, очередь, отчёты, backoff и multi-turn уже реализованы в
`prompt_dispatcher.py` / `prompt_queue.py` / `wrapper.py` / `model_gateway.py`.

**Урок:** перед разработкой обязателен аудит существующего (Этап 1-2 промт 81).
Недостающим оказался именно «человеческий» слой: чтение стартового экрана,
выбор доступной мощной модели по убыванию, таймер сессии с сохранением
контекста. Проект — тонкая обёртка (Additive), а не переписывание.

## CON-2 (2026-08-12): выбор модели — не HTTP-провайдер, а стартовый экран TUI

**Сценарий:** 081_19_model_dispatcher требует «отправлять в нужную LLM (DeepSeek, GLM,
MiniMax)». GLM/MiniMax как HTTP-провайдеров в `model_gateway.py` нет, ключей
нет. Но freebuff сам показывает доступные модели на стартовом экране
(«Start coding for free», квоты премиум-пула).

**Урок:** способ интеграции определяется реальным инструментом: имитация
человека (tmux + capture-pane + ArrowDown ×N + Enter) использует нативные
механизмы freebuff, а не обходит их. Это соответствует замыслу пользователя
(«скрипт имитировал действия человека»).

## CON-3 (2026-08-12): «часовая сессия не исчезает» = таймаут без kill

**Сценарий:** таймер сессии (~1 час), задачу можно прервать и вернуться через
3 часа, сессия не теряется.

**Урок:** при таймауте tmux-сессия НЕ убивается — контекст сохраняется
(`save_context` + `freebuff --continue`). Отсюда инъектируемость tmux-операций
в `md_freebuff.py` (unit-тесты без реального tmux).

## ANTI-1 (2026-08-12): не дублировать prompt_queue

**Сценарий:** сначала хотелось переиспользовать `scripts_01.prompt_queue`.

**Урок:** для портируемости проекта (PROJECT_RULES §7 — без жёстких
зависимостей от платформенных скриптов) `md_queue.py` реализует совместимый
формат файлов сам (та же структура `pompts_11/`), но не импортирует
платформенные модули. Формат остаётся совместимым — очередь общая.
