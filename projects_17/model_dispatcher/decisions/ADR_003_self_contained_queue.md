# ADR-003: Самодостаточная очередь (md_queue) без импорта платформенных скриптов

**Статус:** ✅ Accepted (2026-08-12)

## Context

Очередь `pompts_11/{user,running,done,failed***REMOVED***` уже существует в платформе
(`scripts_01/prompt_queue.py`, promt 48). Но PROJECT_RULES §7 требует, чтобы
код проекта не имел жёстких зависимостей от платформенных модулей
(портируемость).

## Decision

`md_queue.py` реализует **совместимый формат** файлов промтов самостоятельно:
та же структура папок, та же шапка (`# TASK:` + `**Ключ:** value` + `---` +
тело + `## Отчёт`), те же правила перемещения файлов. Платформенные скрипты
не импортируются. Общая очередь используется обеими системами без конфликтов.

## Альтернативы

1. **Импортировать scripts_01.prompt_queue** — жёсткая зависимость проекта от
   платформы, нарушает PROJECT_RULES §7. ❌
2. **Своя БД/SQLite** — избыточно для файловой очереди, нарушает совместимость. ❌

## Consequences

+ Проект портируем (самодостаточен).
+ Формат совместим — можно передавать файлы между диспетчерами.
− Небольшое дублирование логики (приемлемо ради изоляции, ANTI-1).
