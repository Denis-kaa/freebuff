# ADR-002: Таймер сессии (1 час по умолчанию) + сохранение контекста

**Статус:** ✅ Accepted (2026-08-12)

## Context

Пользователь: «есть таймер, ориентированный на час; можно прерваться и
вернуться через три часа, при этом сессия не исчезнет». Ограничение:
freebuff допускает один живой инстанс (CON-33).

## Decision

- Таймер сессии по умолчанию **60 минут** (`config.yaml → session.timeout_minutes`).
- При таймауте tmux-сессия **НЕ убивается**: `save_context()` пишет состояние
  (tmux-имя, модель) в `.md_state/<task_id>.json`, задача остаётся в `running/`
  с пометкой «Отложено (таймер сессии)».
- Продолжение — новый запуск с `freebuff --continue` (или re-attach к живой
  tmux-сессии).

## Альтернативы

1. **Жёсткий kill при таймауте** — теряется контекст, противоречит требованию. ❌
2. **Фоновый демон-продлеватель** — сложно, риск OOM на Termux. ❌ (отложено)

## Consequences

+ Сессия переживает паузы (в т.ч. 3 часа).
+ Дешево: файл состояния вместо демона.
− Пока нет авто-resume (этап 9 ROADMAP): продолжение — ручная команда `--once`
  после освобождения инстанса.
