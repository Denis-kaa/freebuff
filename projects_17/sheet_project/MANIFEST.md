## Назначение

Конфигурируемый генератор Excel-дашбордов (архитектура **D2**): структура XLSX, данные, стили, правила отображения и проверки **отделены от кода генератора**.

Первый результат — рабочий эталонный XLSX для управления проектами, полностью собранный через эту архитектуру. Затем та же архитектура позволяет делать другие XLSX без переписывания ядра генератора.

## Архитектура (кратко)

```
CONFIG → GENERATOR → XLSX
             ↑
           DATA
           STYLES
           VALIDATION
```

- **CONFIG** — декларативное описание структуры (листы, колонки, KPI, блоки, карточки, справочники, правила).
- **DATA** — нормализованные входные данные (именованные коллекции `projects`/`tasks`, не зависят от источника).
- **GENERATOR** — ядро, создающее XLSX (без бизнес-логики конкретного шаблона).
- **VALIDATOR** — структурная проверка результата (отдельно от расчёта формул).
- **STYLES** — визуальная конфигурация.

## Ограничения (из promt1.md)

- Без VBA, без макросов.
- Не зашивать структуру конкретного проекта в генератор.
- Не создавать отдельный генератор под каждый XLSX.
- openpyxl **не вычисляет** формулы — только пишет их (расчёт — отдельный слой).
- Без внешних интеграций (Bitrix24 / Google Sheets / API) на первом этапе.
