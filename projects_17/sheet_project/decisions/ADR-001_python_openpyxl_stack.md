# ADR-001 — Стек: Python 3 + openpyxl

> Статус: 🟢 ACCEPTED · 2026-08-18

## Context

Нужен конфигурируемый генератор XLSX без VBA/макросов. openpyxl — фактический стандарт Python для XLSX, уже установлен в проекте (3.1.5) и закреплён в `requirements.txt`.

## Options Considered

1. **Python + openpyxl** — выбран.
2. Python + xlsxwriter — пишет XLSX, но не читает (validator не сможет перечитать результат).
3. LibreOffice headless — умеет считать формулы, но громоздкий; оставляем как опциональный слой расчёта.
4. JS (exceljs) — другой язык/стек, лишний разрыв с платформой.

## Decision

Python 3 + openpyxl для генерации и структурной валидации.

## Rationale

- openpyxl умеет и писать, и читать XLSX → validator может перечитывать результат.
- Уже в зависимостях платформы (`openpyxl>=3.1.0`).
- Покрывает всё из promt1.md, кроме расчёта формул (это явное ограничение — отдельный слой).

## Consequences

- ✅ Один инструмент для записи и чтения.
- ⚠️ Формулы не вычисляются → расчётная валидация выносится отдельно (LibreOffice, опционально).
