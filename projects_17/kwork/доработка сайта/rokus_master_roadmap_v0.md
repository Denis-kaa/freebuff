## 1. Executive Summary

**Проект:** редизайн и доработка `https://rokus-sport.ru/` (Tilda) для производителя спортивной экипировки «Рокус».
**Скоуп:** глобальные правки (шапка, соцсети, активный телефон, карты, кнопки «поделиться»), 10-блочная главная, 4 страницы видов спорта, страницы «Готовая форма», «Скачать каталог», «Партнёры», «Партнёрство», «Ваш мерч» + индивидуальные страницы партнёров.
**Текущее состояние (FACT):**
- Сайт работает на Tilda, есть корзина Tilda Store (`t-store`, `t706`), 32 кнопки Tilda Forms, слайдер (`t-slds`), 4 страницы видов спорта (футбол, волейбол, баскетбол, ХОККЕЙ), страницы `/tkani` и `/infoblok` уже опубликованы.
- Меню НЕ содержит выпадающего «Виды спорта» — разделы вынесены как отдельные URL.
- Соцсети: ОК, VK, **WhatsApp** — WhatsApp нужно убирать (ТЗ).
- В ТЗ упомянуто только 4 вида спорта, а на сайте уже есть **хоккей** — `[NEEDS VERIFICATION***REMOVED***` с заказчиком.
**Цель roadmap:** превратить ТЗ в рабочий план реализации так, чтобы разработчик мог выполнять задачи последовательно без переинтерпретации.

## 14. QA Plan

### Visual QA
- spacing (отступы) — соответствие макету, особенно Hero «5 буллетов».
- typography — заголовки H1 один на странице, чёткая иерархия.
- alignment — выравнивание карточек.
- colors — палитра ТЗ не описана, использовать брендовые `[NEEDS VERIFICATION***REMOVED***` (лого, цветовая гамма Рокуса).
- images — все с alt, без 404.
- buttons — все кликабельные, hover-состояния есть.
- cards — равная высота внутри сеток.
- sections — фоны, переходы между секциями.

### Responsive QA (RULE 5)
- Desktop ≥1280px
- Laptop 1024–1280px
- Tablet 768–1024px
- Mobile 320–768px (включая 360, 414 для iPhone)

### Functional QA
- forms — submit-тест на каждую форму, лог-файл CRM webhook.
- links — no broken (включая якоря).
- buttons — CTA каждой кнопки.
- menus — dropdown открытие/закрытие, escape, focus-trap.
- anchors — `#catalog-download` от шапки → якорь на главной.
- integrations — Tilda Forms → CRM, VK widget рендер.

### Content QA
- spelling (русский).
- punctuation.
- missing text — пустые блоки.
- duplicated text.
- wrong links — все ссылки на правильные URL.

### Technical QA
- console errors (0 на каждой странице — браузерная проверка).
- broken resources — 404 на ассеты.
- layout overflow — горизонтальный скролл на любой странице = баг.
- performance — PageSpeed ≥ 80 (mobile).
- mobile rendering — Touch-events работают.
