## 🧭 Легенда (5 колонок)

| Колонка | Что показывает |
|---------|----------------|
| **Файл** | имя + размер в KB (`image1.png` = hero, и т.д.) |
| **Блок ТЗ → Страница** | какой блок ТЗ и на каких именно страницах сайта используется |
| **Owner** | 🎨 **Заказчик** отвечает за фото / 🔧 **Буффи** делает компонент сам / ⚙️ **Tilda-стандарт** (встроенный Zero Block) |
| **Tilda-компонент** | какой Zero Block или встроенный блок будет использован; `TASK-NNN` ссылается на Master Roadmap |
| **Q-B** | 🟢 OK / ⭐ Блокирующий вопрос заказчику (нужен ответ перед стартом) |

**Иконки Owner (расширенная версия для созвона):**
- 🎨 **Заказчик** = «Клиент присылает фото, я (Буффи) встраиваю без переделок»
- 🔧 **Буффи** = «Я делаю сам из материалов ТЗ / генерирую / оптимизирую»
- ⚙️ **Tilda** = «Встроенный Zero Block, делается в редакторе Tilda за 15 минут»
