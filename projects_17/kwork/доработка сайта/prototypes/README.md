## Шкала размеров (по file_size)

Эвристика по размеру файла **не заменяет** `bytes/pixel`-анализ из [`image6_QA.md`***REMOVED***(image6_QA.md) — там подробнее про hero-качество и артефакты.

- **>300 KB** — скорее всего полноцветное фото или скриншот композиции обложки (image1, image3, image4, image7, image10, image13)
- **~150–300 KB** — фото + графика / скриншот блока с деталями (image6 ⚠️ JPEG, image8, image11, image12)
- **<60 KB** — сжатые иконки, диаграммы или узкие UI-полосы (image2, image5, image9, image14)

## Что отсутствует

В `word/media/` внутри `.docx` НЕТ:
- логотипов партнёров (страница «Партнёры (общая)»),
- фото команд-чемпионов (раздел «Наши чемпионы»),
- фото материалов по каждому из 10 видов ткани (только один пример),
- фото готовых работ (для «Примеры наших работ» — есть только скриншот общего стиля).

Эти материалы нужно либо запросить у заказчика, либо вытащить с текущего `https://rokus-sport.ru/` (Этап 2 promt1.md — «Аудит существующего сайта»).
