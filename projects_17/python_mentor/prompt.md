ЗАДАЧА: подготовить деterministic (без LLM) ядро для системы обучения
Python — этап разведки и предложения архитектуры, БЕЗ немедленного
написания продакшн-кода.

КОНТЕКСТ:
Заменяем часть ролей LLM-системы на детерминированную логику:
- Куратор → rules-engine поверх competency map (условия перехода уже
  формализованы, просто конечный автомат)
- Ревьюер (оси Python + часть Engineering) → автогрейдер: pytest на
  корректность + статический анализ (длина функций, цикломатическая
  сложность, вложенность)
- Ментор (частично) → AST-паттерн детектор известных ошибок
  (mutable default argument, голый except:, O(n²) там где просился dict
  и т.п.) + банк заготовленных подсказок L0–L6 под каждый паттерн
- Spaced repetition → готовый алгоритм (SM-2 или FSRS), не своя логика
- Заказчик → дерево вопрос-ответ по заранее написанным ТЗ

ЭТАП 0 — СБОР ГОТОВОЙ БАЗЫ УРОКОВ/УПРАЖНЕНИЙ (делать ДО остального
research, это основа, без которой Тьютор/Практикум нечем кормить):

1. Найти ОТКРЫТО ЛИЦЕНЗИРОВАННЫЕ банки упражнений и уроков по Python:
   - exercism/python (GitHub, открытая лицензия) — готовые задачи +
     тесты, идеально ложится на автогрейдер.
   - freeCodeCamp curriculum (открытый исходник) — если там есть
     python-трек.
   - Google's Python Class (Apache 2.0).
   - MIT 6.0001 problem sets (проверить лицензию конкретного семестра).
   - Официальная документация Python (tutorial exercises) — free to use.
   ВАЖНО: для каждого источника явно проверяй лицензию ПЕРЕД тем как
   класть контент в базу. Что под закрытой лицензией / просто с сайта
   без разрешения — не трогать, даже если легко скачать.

2. Каждое найденное упражнение смаппить на компетенцию из Curriculum
   Map (документ 2 методики: переменные, циклы, функции, структуры
   данных, ООП, ошибки, файлы, тестирование и т.д.) — не складывать
   в общую кучу, а привязывать exercise → competency → уровень
   сложности (по лестнице: повторение → применение по аналогии →
   новая задача → незнакомый контекст → комбинация → самостоятельная
   задача).

3. Для каждого упражнения сохранить: условие, эталонное решение,
   тесты (если есть готовые — использовать их как основу автогрейдера),
   известные типичные ошибки (если источник их документирует).

4. ОТЧЁТ: сколько упражнений реально набралось на каждую компетенцию,
   и главное — где ПРОБЕЛЫ (компетенции, где легального контента мало
   или нет вообще — по ним честно скажи, что banka придётся собирать
   вручную или разово прогнать через ЛЛМ, не выдавай пробел за
   готовое).

ЭТАП 1 — RESEARCH (обязательно веб-поиском, не по памяти):
1. Существующие open-source автогрейдеры Python-упражнений (Exercism

   — это критично, мы будем исполнять чужой код на своём сервере.
