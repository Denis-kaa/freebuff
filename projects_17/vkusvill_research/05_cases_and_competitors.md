- [НЕТ ДАННЫХ***REMOVED*** Точные KPI (forecast accuracy, списания %).
- [НЕТ ДАННЫХ***REMOVED*** Конкретные РЦ, dark store стратегия Магнита.

### Яндекс.Лавка

- [ФАКТ***REMOVED*** **Forecasting:** Используется **CatBoost** (ML-фреймворк Яндекса) для **прогноза по часам** для 500+ дарксторов. Прогноз служит базой для WFM (расчёт курьеров) и планирования товарных запасов (S058).
- [ФАКТ***REMOVED*** **WFM:** Используется **TARGControl** (или аналог) для автоматизации графиков, учёта рабочего времени (биометрия, геозоны) и **«биржи смен»** (S058).
- [ФАКТ***REMOVED*** **Роботизация складов:** Внедрены **AMR (autonomous mobile robots)** от «Яндекс Роботикс» для перемещения стеллажей. **+30% скорость комплектации**, **+15% плотность хранения** (S058).
- [НЕТ ДАННЫХ***REMOVED*** Конкретные KPI прогноза (MAPE).

**Compare с ВкусВилл:** Яндекс.Лавка **очень близкий аналог** ВкусВилл по модели (e-grocery, dark stores, last-mile). ВкусВилл использует **AGV** (Stage 1 S030) — Яндекс.Лавка использует **AMR**. Оба инвестируют в роботизацию складов. По стеку ML (CatBoost) — вероятно **схожий стек**, поскольку CatBoost принадлежит Яндексу.
