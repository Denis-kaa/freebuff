# 06_AUTONOMY_MAP — оценка автономности по этапам

| Этап | Автономность | Обоснование |
|---|---|---|
| Research (вакансия, источники, инструменты) | 100% | web_search + живые curl-проверки источников |
| Architecture | 100% | паттерны уже в платформе (lead_aggregator) |
| Code | 100% | адаптеры, парсер, дедуп, БД, бот — по готовым паттернам |
| Tests | 100% | hermetic-тесты (FakeScraper DI, без сети) |
| Docker | 100% | Dockerfile + docker-compose |
| Local deployment | 100% | запуск + прогон в локальной среде |
| Server deployment | 80% | нужен SSH-доступ и секреты от человека |
| Proxy acquisition | 40% | провайдер-агностична реализация; выбор+оплата — человек |
| CAPTCHA | 0% | внешний платный сервис, требует аккаунта |
| Credentials (API keys, токены) | 0% | только человек |
