## Что означают маркеры

| Маркер | Когда использовать | Переходит в… |
|---|---|---|
| **CON-NNN** | Подтверждённый опытом урок — можно цитировать в следующих проектах | Остаётся CON |
| **CAN-NNN** | Гипотеза / канонический подход, ещё не подтверждённый в проекте | После подтверждения → CON-NNN (или остаётся CAN, если гипотеза) |
| **ANTI-NNN** | Анти-паттерн (что НЕ делать) — обязательно фиксируется, чтобы не повторять | Остаётся ANTI |
| **PB-NNN** | Процессный баг (вина в процессе/инструменте, не в коде) | Остаётся PB; фикс — в процессе |

## Шаблон записи

Скопировать блок ниже и заполнить при первом уроке:

```markdown
### CON-NNN: <краткое название>
**Дата:** YYYY-MM-DD
**Контекст:** в каком шаге / задаче возникло
**Следствие:** что это меняет в следующих шагах (1-2 предложения)

<детальное описание 2-5 предложений>

**Связанные файлы:** `STEP-XXX`, `ADR-NNN_*.md`, коммит.
```

> Аналогичные шаблоны для **CAN**, **ANTI**, **PB** — структура та же, отличается только маркер.
