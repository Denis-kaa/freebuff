## 3. Генерация workflow заказа (§9 промта)

```
Параметры заказа → правила генерации:
  услуга S-01 → [OP-01, OP-02, OP-04]
  + люверсы → +OP-13 ; + загибка → +OP-14 ; + ламинация → +OP-08
  + монтаж → +OP-19 (в конце, после КК)
  отказ клиента от ламинации → OP-08 автоматически исчезает
```

Правила генерации — данные (`service → operations map`, `param → condition`), редактируемые в настройках. Порядок операций — по полю `order` и зависимости (montage всегда последняя).

## 4. Критерии готовности (§10)

У каждой операции `done_criteria` — список проверок; операция не может быть отмечена выполненной, пока не пройдены пункты чек-листа (кнопка «Готово» без галочек не активна). Пример для OP-02: размер = заказ; вылеты есть; текст в кривых; цвет CMYK; файл открывается после экспорта.
