## 2. Карта «старое → новое»

```
Калькуляторы: 7 calculate()          → PrintCalc Pro: calculators/<id>/calc.py
CopyCentre: модели/диапазоны/опции   → data/registry/pricing.yaml (единый формат)
CopyCentre: импорт Excel             → services/pricing_import.py (+шаблон xlsx)
CopyCentre: отчёты (headers/columns) → web: настраиваемые колонки отчётов
ComplexControls: гриды               → web: таблицы с суммами/фильтрами
design_calc: PDF                     → services/pdf.py (все модули)
WF: заявки/процессы (HelpDesk идея)  → V2: orders/ (смета→заказ→статусы)
WF: конфиг (URL/локаль/обновления)   → settings.yaml + автообновление (V2)
```

## 3. Несовместимости

- Стеки (.NET 3.1 vs Python) — несовместимы напрямую; перенос — через переосмысление форматов данных, не кода.
- WF требует сервер WorkflowEngine — в целевом заменяется встроенным backend.

## 4. Verdict

Объединение выполняется **в сторону целевого web-приложения (PrintCalc Pro)**: калькуляторы дают расчётное ядро, WorkflowForms — зрелые продуктовые паттерны (прайс-модель, Excel-импорт, гриды, заявки). Сам WF остаётся источником требований, не кода.
