# UI_ARCHITECTURE.md — информационная архитектура интерфейса

> Статус: COMPLETE · Дата: 2026-09-07

## 1. Главный экран `/`

- Поиск по калькуляторам; категории (Печать / Наружная реклама / Дизайн / Производство);
- «Последние использованные» и «Избранные» (localStorage → V1 серверные);
- быстрый запуск: 1 клик до формы расчёта.

## 2. Каталог `/calculators`

- Карточки: название, категория, краткое описание, «что считает» (цена/себестоимость);
- фильтр по категории + поиск; отключённые калькуляторы скрыты (enabled реестра).

## 3. Экран калькулятора `/calculators/:id`

- Название + краткое описание (из metadata);
- форма по input-schema: поля с единицами (см/м/м²/шт), подсказки, дефолты;
- кнопка «Рассчитать» (и живой пересчёт для простых схем);
- результат: **Цена клиенту** (крупно), Себестоимость, Прибыль/маржа %, детализация breakdown, warnings («учтён мин. тираж 500», «нет ставки — задайте в справочнике»);
- дополнительные параметры в сворачиваемом блоке; «Копировать результат», «В смету», «Экспорт CSV/PDF».

## 4. Смета `/estimate`

- Таблица позиций (описание, кол-во, цена), итого; удаление/очистка; сохранение черновика (localStorage в MVP); экспорт CSV/PDF.

## 5. Настройки `/settings` (роль admin, V1)

- Справочники: материалы, прайсы, оборудование, налог, мин. заказы; включение/отключение калькуляторов.

## 6. Карта маршрутов

```
/
├── /calculators
│   └── /calculators/:id          # рендер по input_schema
├── /estimate
└── /settings
    ├── /settings/registry        # справочники
    └── /settings/calculators     # вкл/выкл, порядок
```

## 7. Мобильный сценарий

- Responsive: каталог и форма в 1 колонку, результат sticky-блоком; смета — полноэкранный список. Минимум тапов: главный → калькулятор → расчёт.

## 8. DoD

- [x] каждый сценарий имеет маршрут; [x] тупиков нет (из любого экрана есть «назад»/каталог); [x] единый UX-паттерн калькуляторов; [x] мобильный сценарий предусмотрен; [x] UI соответствует backend-контрактам (schema-driven).
