## 1. Дерево настроек (§36)

```
Настройки / Администрирование
├── Услуги          — CRUD услуг, категории, описание, единица, вкл/выкл, порядок
├── Категории       — дерево (SERVICE_CATALOG §8)
├── Материалы       — реестр (MATERIAL_MODEL §1): цены закупки, нормы, поставщики
├── Цены            — прайсы по услугам (позиции, диапазоны, cost/sell)
├── Калькуляторы    — поля schema, обязательность, формулы-константы, мин.цена
├── Доп. услуги     — справочник доп-услуг (название, цена, единица, условие)
├── Правила рекомендаций — upsell_rules.json (R-01…R-n)
├── Вопросы         — схемы вопросов (QUESTION_FLOW §1)
├── Скрипты         — шаблоны диалога (SALES_SCRIPT §3)
├── Термины         — глоссарий (TERMS_GLOSSARY)
├── Расходы         — закупки, статьи накладных (universal: аренда, ЗП, реклама…)
├── Остатки         — дашборд + коррекции
└── Общие настройки — налог, округление, валюты, исполнители (managers: EXISTING 2 шт)
```

## 2. Что переносится из кода в настройки (§28 — карта миграции)

| Было в коде | Куда | Сложность |
|---|---|---|
| Весь прайс Riso (riso_calc.py:26-96) | Цены → Ризограф | низкая (RisoConfig уже инъекционный в printcalc) |
| TAX_RATE=0.06 ×3 файла | Общие настройки | низкая |
| MIN_ORDER (riso 500 / digital 500) | Общие → по услуге | низкая |
| Наценки default (25/30%) | По услуге | низкая |
| Шаг люверсов 50 | Общие → доп-услуга | низкая |
| Коэффициенты сложности (все 1.0) | По услуге (иначе скрыть поле) | низкая |
| Ширина буквы = 0.7×высоты (BR-11) | Калькуляторы → параметры правила | средняя |
| Раскрой/зазор 2 мм | Калькуляторы → Digital | низкая |
| Плейсхолдеры скриптов | Скрипты | средняя (новое) |
| Нормы расхода (equipment.json ink_per_1000 и др.) | Материалы → нормы | низкая |

**Честное ограничение (§37):** формула нового типа расчёта не описывается данными — новая услуга со стандартной структурой (материал×площадь×тираж+допы) добавляется из шаблонов без кода; нестандартная (например, световая электрика BR-12) требует нового compute-модуля программистом — это зарегистрированное исключение.

## 3. Существующие редакторы (сохраняются как основа)

- M1: add/delete_price_item, save_form_schema (JS-bridge) — прототип разделов «Цены» и «Вопросы».
- M2: CRUD материалов/ставок — прототип «Материалы».
- M4/M5/M6/M7: деревья прайсов + автосохранение JSON — прототип «Цены».
- M8: редактор оборудования/материалов — прототип «Расходы».
- WF CopyCentre: модель + до 10 диапазонов тиража; импорт прайсов из Excel с отчётом Success/Failed — паттерн для массового импорта (V2).

## 4. Права и данные

- Роли: владелец (всё), менеджер (расчёты/заказы, цены — просмотр), производство (операции). RBAC-паттерн — см. pmos_work/backend/app/rbac.py (уже в репозитории платформы).
- Хранилище: SQLite (продакшн) / JSON (desktop-вариант) через один Repository-слой; все правки цен — с журналом (кто/когда/было→стало) — этого в legacy нет, история цен нужна для разбора споров.
- Валидация: цена ≥ 0; нулевые цены — предупреждение (урок BR-W2); удаление материала — только если не используется в прайсах.

## 5. Изменение цены без кода — сквозной сценарий проверки

Владелец: Настройки → Цены → Ризограф → «A4, 1000–1999, односторонняя: 0.45 → 0.48» → сохранить → расчёт 1200 А4 сразу даёт новую цену → golden-тест движка обновляется по конфигу, не по коду (printcalc инъекция RisoConfig это уже умеет — тест 5 в test_riso_golden.py).
