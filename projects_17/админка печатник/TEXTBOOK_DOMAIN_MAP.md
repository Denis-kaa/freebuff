## 1. Область как цепочка (скелет учебника)

```
КЛИЕНТ с задачей
   │
   ▼
ПРИЁМ ЗАКАЗА ────────────── глава 15 (вопросы по типам заказов), глава 1 (роль)
   │   «что спросить» — QUESTION_FLOW/SALES_SCRIPT как основа
   ▼
РАСЧЁТ ──────────────────── главы 3–4 (материал×технология=цена), глава 10 (расход)
   │   калькуляторы «Печатника» — живые примеры расчётов
   ▼
МАКЕТ / ФАЙЛ ────────────── глава 14 (CMYK, DPI, вылеты, форматы файлов)
   ▼
ПРОИЗВОДСТВО ────────────── глава 4 (технологии печати) + глава 5 (оборудование)
   │   │
   │   ├─ ПЕЧАТЬ: цифровая / широкоформатная / UV / сублимация / ризограф / офсет…
   │   └─ ИЗДЕЛИЕ (не печать): объёмные буквы, монтаж конструкций, сувенирка
   ▼
ПОСТПЕЧАТНАЯ ОБРАБОТКА ──── глава 6 (резка/контур/люверсы/ламинация/сварка…)
   ▼
КОНТРОЛЬ + УПАКОВКА ─────── глава 22 (чек-листы «перед запуском», «перед выдачей»)
   ▼
ВЫДАЧА / МОНТАЖ ─────────── главы 7 (вывески), 10 (баннеры), монтаж как услуга
```

Сквозной принцип ТЗ: каждое понятие = «что это → как выглядит → зачем → где
применяется → пример реального заказа».

## 3. Схема связей (главные «мостики» между осями)

1. **Задача → материал:** где используется (улица/помещение) + срок + бюджет →
   выбор класса материала (Frontlit 440 vs 510, ПВХ 3мм vs композит).
2. **Материал → технология:** не всякий материал печатается всякой печатью
   (UV на жёстких, экосольвент на плёнках, сублимация на текстиле) — ТЗ §4.
3. **Технология → оборудование:** чем печатаем/режем в этой мастерской vs подряд.
4. **Изделие → обработка:** наклейка → контурная резка; баннер → люверсы/карманы/сварка.
5. **Расход ≠ геометрия:** раскрой, рулон, отходы (ТЗ §10) — живой пример
   wide-калькулятора «Печатника» (расчёт тиражной площади).
6. **Контурная резка → макет с контуром → плоттер** — сквозной кейс, совпадает
   с golden-фразой Smart Order и вопросом `layout_with_cut_contour`.

## 4. Инвентарь: что уже есть vs что исследовать

### Готово (переиспользуем как фактурную базу, с проверкой дат)
- **research/00–17**: методология грейдов A–E, компании/услуги района, прайс-реестр
  (119 строк RAW), синонимы, ambiguities, гео-каскад (17_catalog_prices).
- **QUESTION_FLOW/SALES_SCRIPT/UPSELL_RULES/BUSINESS_RULES**: основа глав 15/22.
- **TERMS_GLOSSARY**: стартовый костяк словаря (гл. 16).
- **OPERATIONS_CATALOG**: постпечать и операции (гл. 6).
- **Прайс-книга и калькуляторы**: реальные формулы расхода (гл. 10) и живые цены.

### Исследование нужно (глубина по ТЗ)
1. **Материалы** — теххарактеристики от производителей (плотности, толщины,
   printable/ cut / bend / laminate …): 7 групп × ~10–15 материалов.
2. **Технологии печати** — 13 технологий: принцип, материалы, DPI-требования,
   долговечность (интерьер/экстерьер), когда выбирают.
3. **Оборудование** — 15 групп: классы устройств, ограничения, типичные ошибки.
4. **Вывески/конструкции** — 17 типов изделий: состав, материалы, монтаж, ценообразование.
5. **Фото- и сувенирная часть** — технологии (сублимация/DTF/DTG/термотрансфер) и параметры.
6. **Фотобанк главы 19** — подбор 60–100 изображений с подписями и сравнениями.

### Принцип честности (наследие research-протокола)
Каждая существенная характеристика → источник. Расхождения производителей →
таблица «зависит от…». Нет открытого прайса → «цена по запросу» (конвенция каталога).

## 5. Формат итогового артефакта

- Каталог `projects_17/админка печатник/учебник/`: по файлу на главу (учебник.md-сеть),
  `00_sources.md` — общий реестр источников; изображения — `учебник/images/<глава>/`.
- Каждая глава: цели → основной текст (связи, таблицы, сравнения) → мини-кейсы →
  ошибки новичка по теме → источники главы.
- Финальные шпаргалки (гл. 22) — отдельный файл, собранный из глав.
