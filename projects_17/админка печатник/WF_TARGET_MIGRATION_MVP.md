## 1. Целевая архитектура (дополнение к TARGET_ARCHITECTURE.md)

PrintCalc Pro расширяется слоями из WorkflowForms-наследия:

```
Web UI
  ├── Каталог калькуляторов (7 модулей)
  ├── Прайс-реестр: модели + параметры + диапазоны 1–10 + опции   ← CopyCentre-модель
  ├── Импорт прайсов из Excel (шаблон, валидация, отчёт)          ← CopyCentre
  ├── Смета → Заказ (статусы)                                     ← HelpDesk-идея (V2)
  └── Настройки (справочники, роли)
Backend (FastAPI)
  ├── Calculator Engine (CALC-контракт)
  ├── Pricing Registry (единый формат прайсов)
  ├── Pricing Import Service (openpyxl; шаблон xlsx; Temp→commit; отчёт Success/Failed)
  ├── Orders Service (V2)
  └── Export Service (CSV/PDF; XLSX/DOCX по шаблонам — замена Office Interop)
Persistence: SQLite (заказы/история) + YAML/JSON (реестры, git-friendly)
```

## 2. Архитектура калькуляторов

Без изменений относительно CALCULATOR_ARCHITECTURE.md; input_schema расширяется типом `price_model` (ссылка на модель прайса с диапазонами) — калькуляторы Riso/Wide/Digital/Tablichki/Sign/Costing переключаются на общий реестр цен.

## 3. UI-архитектура (дополнение)

- `/pricing` — прайс-реестр: модели, диапазоны, опции; импорт Excel (загрузка → предпросмотр → подтверждение → отчёт).
- `/orders` (V2) — список заказов, статусы, связь со сметами.
- Таблицы — с суммами по колонкам, фильтрами, комбо-колонками (паттерн ComplexControls).
