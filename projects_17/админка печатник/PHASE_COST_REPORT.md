## 1. Что сделано

- **Найден legacy-исходник:** «Калькулятор себестоимости/universal_calc.py»
  (1168 строк) + equipment.json (6 станков). Это **внутренний** калькулятор:
  считает не «цену из прайса», а **себестоимость** задачи по станку —
  амортизация + сервис + электричество + расходники + оператор + накладные,
  сверху наценка 30% (дефолт GUI).
- **Пакет `printcalc/calculators/cost/`** (аддитивно):
  - `config.py` — модель Equipment/MaterialSpec + **equipment_data.json** —
    дословный перенос 6 станков: Roland VP540/SJ645 (wide), Xerox Phaser
    7760 (digital), Riso RZ300EP (offset), ламинаторы Bulros FM650A/FGK 320.
    EconomicsDefaults — дефолты GUI (накладные 80000/мес, загрузка 0.8,
    оператор 300 ₽/час, наценка 30%, брак 0%). Формулы машино-часа
    (amort + maint + elec) — parity строк 432–439.
  - `spec.py` — CALC-SPEC: equipment/material (STRING, наборы из конфига),
    qty, sheet_format (A7…A0), use_custom + custom_width/height (мм).
  - `compute.py` — порт calc_price_for_job (449–587) по kind:
    wide — ₽/м²·qty + чернила мл/м²·₽/мл·qty; digital — раскладка
    custom-размера (floor), тонер × листов; offset — краска л/1000 +
    **мастер на задачу**; lamination — ₽/м² площади, расходники 0.
    Накладные = сумма/машино-часы всех станков (653.3̅ ч/мес).
    Отсутствующий материал → первый ключ (parity).
- **Регистрация:** мост — register_cost, опции equipment/material из
  конфига. **Реестр = 8 калькуляторов** (cnc, cost, design, digital,
  riso, sign, tablichki, wide).
- **Парсер:** ключ «себестоимост» → intent cost (для ручного ввода
  оператором; клиентское слово маловероятно).
- **Golden-тесты `test_cost_golden.py`** (10 кейсов) с независимой деривацией:
  - Машино-час: VP540 = **91.00 ₽** (70+6+15), Xerox = **17.26̅ ₽**
  - Wide: баннер 10 м² VP540 → total **1647.8741496598639**, цена **2142.24**
  - Digital custom: 500 визиток 90×50 → 50 листов (10/лист), цена **857.5379**
  - Offset: Riso 100 А4 → мастер 2500 + краска 6, цена **3859.3300**
  - Lamination: 5 А4 → расходники 0, цена **49.5364**
  - Fallback материала/масштаба, валидация (неизвестный станок, qty=0,
    изделие не влезает в лист)

## 2. Находка паритета: латиница/кириллица

Формат «A4» (латиница) не входит подстрокой в материал «Бумага А4 80г»
(кириллическая А) — **и в legacy тоже**: exact-ветка недостижима, всегда
работает fallback «масштаб от А4-шаблона». Так как tpl_area == sheet_area,
числа совпадают с exact — паритет сохранён, метка «(масштаб A4)» как в legacy.
Задокументировано в тесте; починка соответствия — осознанное изменение
(кандидат в v2, не в порт).
