# 00_methodology.md

## Что это
Рабочая методология исследования «Цифровой помощник ресепшена типографии/фотоцентра/копицентра».
Исполнено по промту `research_prompt.md`: 10 PASS'ов, анти-галлюцинационный протокол, 3 гео-слоя (Россия → ХМАО → Нефтеюганский район).

## Дата исследования
2026-09-09. Все цены — на момент фиксации, без попытки усреднения (§23).

## География
- Уровень 1: Россия (федеральные онлайн-типографии + национальные Q&A-площадки).
- Уровень 2: ХМАО-Югра — Ханты-Мансийск, Сургут, Нижневартовск, Нефтеюганск, Пыть-Ях, Когалым, Нягань, Мегион, Югорск, Советский, Лянтор (частично).
- Уровень 3 (приоритет): Нефтеюганск + Нефтеюганский район, включая Пыть-Ях.

## Типы источников (по приоритету промта §6)
1. Официальные сайты компаний и прайс-страницы (photohotel.ru, fsfera.ru, opt-poligraf.ru, tel86.ru, express72.ru, 66print.ru, fotokadrsurgut.orgs.biz…)
2. Агрегаторы с ценами: Яндекс.Карты (карточки «Точка Печати»), 2ГИС, Zoon, Яндекс.Услуги, Spravker/Jsprav/orgs.biz
3. Q&A и форумы: otvet.mail.ru (полные треды прочитаны, формулировки дословные)
4. VK-группы (fotomirnfy, mirfotohm, fotokadrsurgut) — прямой доступ ограничен, использованы сниппеты поиска
5. Avito (нефтеюганск/пыть-ях/югорск) — прямой доступ ограничен (HTTP 429), использованы сниппеты поиска
6. Отзывы: 2ГИС-оценки из сниппетов, отзывы на photohotel.ru

## Шкала доказательности (§2)
| Уровень | Значение |
|---|---|
| **A** | Подтверждено несколькими независимыми источниками |
| **B** | Подтверждено несколькими компаниями/источниками |
| **C** | Наблюдение у отдельных компаний |
| **D** | Гипотеза, требует проверки |
| **E** | Недостаточно данных |

Ключевые оценки:
- **A**: фото на документы продаются «блоками» (2/4/6/8/9 шт, тип размера зависит от документа); фотопечать тарифицируется размером + тиражной лестницей; ксерокс ч/б — базовая услуга любого пункта.
- **B**: люверсы — стандартная опция баннера; визитки имеют минимальный тираж; переплёт на пружину — отдельная тарифицируемая услуга.
- **C**: региональные особенности ХМАО (см. 10_khmao.md); конкретные цены конкретных точек.
- **D**: частотность заказов (прямой статистики нет — «наличие услуги на сайте ≠ популярность», §24).
- **E**: Малые ИП Нефтеюганского района без сайта/VK (Лангепас, Покачи, Радужный, Пойковский) — прямых прайсов не найдено.

## Протокол честности
1. Каждый вывод в файлах 02–16 несёт метку A–E и источник.
2. Формулировки клиентов — только дословные цитаты с URL источника (04_customer_requests.md). Примеры из промта НЕ считаются результатом.
3. Где данных нет — «Недостаточно данных» (см. 16_findings.md → Limitations).
4. Противоречия показаны парой «Источник A / Источник B» (07_ambiguities.md).
5. RAW-данные отделены от анализа: 01/03 — реестры наблюдений; 04 — дословные цитаты; аналитика — в 06/07/09/12/14/15.

## Ограничения процесса
- VK/Avito: полные тексты недоступны напрямую → использованы поисковые сниппеты; помечено C.
- Яндекс.Карты: цены взяты из карточек в сниппетах; точные тарифные сетки не раскрывались → C.
- Частотность: нигде не заявлена как факт, только D-гипотезы с обоснованием.
- zsa-print.ru (калькулятор Нефтеюганска) не открылся по таймауту — есть только сниппет → C.
