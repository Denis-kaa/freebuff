## Что можно автоматически (по §25 промта, с фактами)

- распознать intent — для всех вышеуказанных (D→B, словарь 08 готов)
- извлечь размер/количество — regex-паттерны «10 15», «2 на 2», «50 на 50» устойчивы (A-паттерн прайсов)
- проверить файл: формат (Word → предупреждение — A), разрешение (детектор «Качество фотографии очень плохое» уже существует на рынке — B)
- посчитать площадь/страницы — арифметика
- предрасчёт по прайсу своей точки — движок (принцип проекта)

## Нельзя без человека (§25 + материал)

- спорный макет (Word, низкое разрешение) — предупреждение + человек
- нестандартная конструкция, замеры (вывески — A)
- неоднозначный материал (табличка — A)
- критическая цветопередача («печать без коррекции» vs автокор лаборанта — A)
- дорогой заказ (крышные установки от 12400₽ — A) — подтверждение сотрудника всегда
- любое обещание цены, которой нет в прайсе (принцип проекта + §2 промта)

## Метрика-предложение для MVP

`automation_score = стандартизированность прайса (0-3) × параметрическая полнота (0-3) / ручные операции (1-3)`
- photo_print: 3×3/1 = 9 → P0
- copy/print/laminate: 3×3/1 = 9 → P0
- document_photo: 3×2/2 = 3 → P1 (съёмка всё равно офлайн)
- business_cards: 3×2/1.5 = 4 → P1
- banner: 2×2/2 = 2 → P2
- signage: 1×1/3 = 0.3 → P3
