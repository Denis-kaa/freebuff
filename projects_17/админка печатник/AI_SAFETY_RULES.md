# AI_SAFETY_RULES.md — правила безопасности при использовании AI

> Статус: COMPLETE · Дата: 2026-09-07 · Связан с AI_ASSISTANT_CONCEPT.md; применяется к любому AI-шагу.

## 1. Жёсткие запреты (не настраиваются)

1. **AI не определяет цену.** Любая цифра для клиента — только из прайса и движка (BR-04, BR-14). AI-текст, содержащий цену, обязан брать её из расчёта по плейсхолдеру, а не «придумывать».
2. **AI не меняет заказ/прайс/остатки автоматически** — только предложение через кнопку подтверждения.
3. **AI не скрывает свою роль:** артефакт помечается «сделано AI».
4. **AI не имитирует документы:** не выдаёт результат за официальный документ (справка, удостоверение, диплом).

## 2. Обязательные проверки после AI-обработки изображений (§5 промта)

- лицо не изменилось (узнаваемость сохранена);
- пропорции не искажены;
- детали не дорисованы (ожерелья, шрифты, логотипы сверить с исходником);
- фон не исказился;
- нет артефактов (руки, текстуры, края);
- результат соответствует требованиям заказа (размер/формат/DPI).

Чек-лист показывается автоматически; закрытие операции с AI-шагом требует его прохождения (PRODUCTION_CHECKLISTS).

## 3. Официальные документы — особый режим

Для фото на документы (паспорт, виза, удостоверение): **генеративное изменение внешности может быть недопустимо** — система обязана показать предупреждение и предложить только допустимые операции (обрезка, фон, размер) из спец-чек-листа. AI-коррекция черт лица — заблокирована по умолчанию; отключение — только явной настройкой владельца с подписью об ответственности.

## 4. Данные и приватность

- В AI не отправляются персональные данные клиентов без явного действия сотрудника (имя/телефон вырезаются из промта автоматически).
- Локальная база знаний (термины/операции) — предпочтительный источник; внешний AI — только для формулировок/советов.
- Всё, что AI вернул, хранится в журнале вместе с промтом (аудит).

## 5. Отказ и деградация

AI недоступен/ошибся → система продолжает работать: вопросы из схемы, правила из upsell.json, операции из каталога. Ни один процесс не блокируется AI.
