## 3. Дерево выбора способа (§6 промта) — пример «фото не подходит для документа»

```
Что нужно? ─┬─ обрезать → любой редактор (альтернатива: онлайн)
            ├─ исправить наклон → ручная правка / AI (AI_SAFETY_RULES)
            ├─ удалить фон → PS / AI-инструмент / онлайн
            └─ под документ → спец-чек-лист (размер/фон/лицо)
```

Каждая ветка показывает: рекомендуемый способ, альтернативы, когда что использовать, плюсы/минусы, что проверить после. Ветки настраиваются; ПО без флага `available=true` показывается приглушённо с пометкой «не установлено».
