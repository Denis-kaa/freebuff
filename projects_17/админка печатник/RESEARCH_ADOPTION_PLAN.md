## 3. Доп. web-исследование (пробелы, которых не было в zip)

1. **Люверсы 2025–2026:** 20 ₽/шт (bannerdom), 50 ₽/шт (СПб), «бесплатно при
   шаге 30 см» (OQ). → Наша цена 20 ₽ — нижняя граница нормы; можно оставить.
2. **Баннер 440 г/м²:** 300–490 ₽/м² (Москва, 360–720 dpi), от 300 ₽/м²
   (регионы). → Наши 280–350 — нижняя треть рынка для региона, ок.
3. **Фотопечать/копии 2026:** фото 10×15 — 15–25 ₽ (Крым 12–50, КВИК 20),
   копия А4 — 5–15 ₽, фото на документы — пакет 4 шт = 400 ₽ (КВИК 2026).
   → Подтверждает коридоры из zip; для Нефтеюганска реалистично 20–30 ₽ фото, 12–15 ₽ копия.
4. **Визитки цифрой:** 962 ₽/100 шт (СПб), 2250 ₽/100 (шелкография Мск),
   пластик от 17 ₽/шт. → Наша базовая 4 ₽/шт дешевле всех — вопрос к Денису.
5. Чего не нашёл даже в web: **региональные цены ХМАО на ретушь/реставрацию**
   (в zip: «от 800 ₽» — Фотосфера, E-уровень). Оставляем как «от».

## 4. Диалоги: R1–R10 → наши экраны и Telegram

Исследование даёт готовый свод правил. Переносим в диалог-слой:

| Правило | Куда встраиваем |
|---|---|
| **R1** один вопрос закрывает максимум дыр | QUESTION_FLOW: групповые вопросы (баннер: «на улицу? люверсы? файл?») |
| **R2** пакетные услуги объяснять | карточка «Фото на документы»: показывать состав пакета, не «×бумага» |
| **R3** новичку — процедура, не цены | подсказки «как заказать» в Входящих (кнопка-шаблон ответа) |
| **R4** файл-валидатор раньше цены | Order v2: поле files + quality_flag (ok/warn/reject) до расчёта |
| **R5** мин. тираж предупреждать ДО расчёта | уже есть: warning в Digital/Riso («Применён минимальный заказ») + показывать в UI диалога до кнопки «Рассчитать» |
| **R6** тиражные ступени показывать активно | в превью калькулятора: «100 шт — по 4 ₽, от 101 — по 3 ₽» |
| **R7** материал не угадывать | INFERRED≠KNOWN: формы без дефолта для материала таблички/баннера (уже частично: required-поля) |
| **R8** мультизаказ — вопросы по позициям | парсер v2 + unassigned_fragments (см. §5-3) |
| **R9** никогда не угадывать: материал, количество в пакете, кадрирование, цену вне прайса, требования документов | assistant intents: never_infer-списки (уже в intents.py) + жёсткий guard в estimate-flow |
| **R10** эскалация человеку при confidence<0.6 / HUMAN-зоне / дорогом заказе | Входящие: статус «нужен оператор» + reasons в карточке (мини-версия 13_order_schema) |

Мини-диалоги (CR-01, CR-02, banner) — готовые шаблоны быстрых ответов
для страницы «Входящие» (Telegram-ответы одной кнопкой).
