# UX_UI_AUDIT.md — UX/UI аудит «Калькуляторы»

> Статус: PARTIAL · Дата: 2026-09-07 · Ограничение: интерактивная проверка GUI невозможна (см. RUN_REPORT §5); аудит — статический по коду/HTML/лейблам. Факты отделены от гипотез.

## 1. Что известно о экранах (из кода)

- **Обёртка**: меню-карточка с 5 кнопками («Ризограф, Таблички, Вывески, Широкоформатка, Цифровая печать»), «Назад», «Выход» (`build_all/all_in_one.py:50-165`).
- **Tk-калькуляторы**: Notebook-вкладки «Калькулятор / Смета / Прайс(ы)»; левая колонка — параметры, правая — результат («Цена клиенту», «Себестоимость», «Прибыль») + текстовый лог расчёта; кнопки «Рассчитать / В смету / Очистить», «Сохранить CSV».
- **Макеты (webview)**: вкладки Расчёт/Форма/Справочники, баннер цены, экспорт PDF, редактор JSON-схемы формы.
- **ЧПУ (webview)**: параметры изделия, материалы и ставки, живой пересчёт `updatePrice()`.

## 2. Проверенные UX-паттерны (факты)

- Единая палитра (BG #f0f4f8, ACCENT #0284c7…) в 6 Tk-файлах — консистентность цветов есть.
- Единый трио-паттерн «Рассчитать → В смету → CSV» в 4 standalone + wrapper-копиях.
- Результат всегда трёхкомпонентный: цена/себестоимость/прибыль — хорошая согласованность.

## 3. Реестр недостатков

| ID | Экран | Проблема | Влияние | Приоритет | Решение |
|---|---|---|---|---|---|
| U-01 | все | два разных UI-стека (Tkinter vs webview-HTML) в одном продукте | разный UX, двойная поддержка | High | единый web-UI в целевом приложении |
| U-02 | обёртка | 2 калькулятора (Макеты, ЧПУ, Себестоимость) не входят в меню | пользователь не находит функции | High | включить все 7 в каталог |
| U-03 | Riso | мин. тираж 500 — константа, UI не предупреждает о подъёме до минимума | неожиданная цена | Medium | явное уведомление «учтено N листов» (лог есть, banner нет) |
| U-04 | формы ввода | валидация только по кнопке «Рассчитать», messagebox-ошибки | медленный ввод, страх ошибки | Medium | inline-валидация + подсказки единиц (см/м/м²) |
| U-05 | Смета | нет сохранения сметы между сессиями (только CSV вручную) | потеря данных при закрытии | Medium | автосохранение черновика |
| U-06 | Таблички | print()-строка «Проверка версии…» видна в консоли при запуске | мусор в UX (консольные сборки) | Low | убрать при миграции |
| U-07 | Макеты | редактор формы = raw JSON textarea |高风险 ошибок пользователем | Medium | структурированный редактор схемы |
| U-08 | все | нет тёмной темы/масштабирования шрифтов | доступность | Low | CSS-переменные/шрифтовые профили |
| U-09 | ЧПУ | «нет ставки» показывается в цене без объяснения где добавить | тупик пользователя | Medium | ссылка-переход к справочнику ставок |
| U-10 | мобильность | desktop-only (Tk/webview окна) | нет мобильного сценария | High (для цели) | web-приложение responsive |

## 4. Пользовательский путь (восстановлен по коду)

Меню → выбор модуля → ввод размеров/тиража → «Рассчитать» → проверка цены/прибыли → «В смету» (несколько позиций) → «Сохранить CSV». Для Макетов: форма → цена по прайсу → PDF-бланк с подписями.
