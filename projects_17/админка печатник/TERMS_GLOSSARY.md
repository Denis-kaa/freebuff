> Статус: COMPLETE · Дата: 2026-09-07 ·
> Метод §26: сначала извлечены термины, реально встречающиеся в коде/прайсах (лейблы UI, названия прайс-позиций, MATERIALS/PRICES dicts), затем — недостающие. Определения терминов — PROPOSED-текст (в исходниках определений нет: grep «справк|инструкц» — 0 совпадений); сами термины — EXISTING.

## 1. Модель записи (§26)

```json
{
  "term": "люверс",
  "short_description": "Металлическое кольцо для крепления баннера",
  "detailed_description": "…",
  "related_services": ["S-01 Баннер", "S-02 Таблички"],
  "tips": "Шаг 50 см — стандарт для баннеров на улице; по периметру через 25 см — для сильного ветра",
  "source": "EXISTING (wide_format.py:66), определение PROPOSED"
}
```

Открывается по ⓘ из любого места интерфейса (CONTEXTUAL_HELP.md). Владелец редактирует в разделе «Термины».

## 3. Недостающие термины (PROPOSED — нужны для выполнения заказов, в коде отсутствуют)

| Термин | Зачем нужен | Связь |
|---|---|---|
| Вылеты (bleed) | Проверка макета: печать за линию реза 2–5 мм | OPERATIONS: подготовка макета |
| DPI / разрешение | Для баннеров 30–70 dpi достаточно, для интерьерки 150+ | OPERATIONS: проверка макета |
| CMYK / RGB / Pantone | Цветопередача, конвертация при подготовке | OPERATIONS: проверка цвета |
| Вектор / растр | Формат файла, критично для плоттерной резки | S-06, S-07 |
| Штанга / профиля крепления | Монтаж баннеров | R-06 |
| Плёнка перфорированная (One Way Vision) | Витрины/авто — часто заказывают | PROPOSED услуга |
| Срок выцветания | Аргумент продажи экстерьерной печати | R-03 tips |
