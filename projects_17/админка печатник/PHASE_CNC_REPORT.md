## 1. Что сделано

- **Найден legacy-исходник:** «Калькулятор фрезерной и лазерной резки/cnc_calc.py»
  (590 строк). Семантика: `рез = длина × ставка ₽/м × qty`,
  `материал = ш×д × ₽/м² × qty`, ИТОГО = рез + материал.
  Legacy НЕ содержит наценку/налог/минималку — перенесено как есть.
- **Пакет `printcalc/calculators/cnc/`** (аддитивно, по образцу digital/sign):
  - `config.py` — канонические константы: 13 материалов (Фанера 3–18,
    Акрил 3–5, ПВХ 3–5, Композит 4–5) + 26 ставок реза
    (laser/frezer × материал × толщина) — дословный перенос.
    Поведение «нет ставки»: рез = 0 + warning, материал считается
    (parity updatePrice, «рез: ставка не задана»).
  - `spec.py` — CALC-SPEC: machine (ENUM laser/frezer), material (STRING
    с опциями из конфига), thickness, cut_length (м), qty, размеры
    изделия в метрах (product_width/product_height — габариты изделия
    из формулы legacy, не поля листа).
  - `compute.py` — чистая функция, паритет float-арифметики;
    price == price_no_tax == cost (нет наценки/налога в legacy),
    net_profit == 0; unit_price = total/qty.
- **Регистрация:** мост `printcalc_web/calculators.py` — register_cnc +
  опции полей из конфига (материалы, толщины); «ЧПУ» доступен в
  диалоге расчёта и схемном UI.
- **Парсер:** ключевые слова «чпу», «фрезер», «лазер», «резк», материалы
  (фанер/акрил/оргстекл/композит) → intent `cnc` (только для сегментации
  входящих сообщений).
- **Golden-тесты `test_cnc_golden.py`** (9 кейсов) с независимой деривацией:
  - Лазер/Фанера 6: 10 м × 25 × 2 + 0.5 м² × 450 × 2 = **950.00** (475/шт)
  - Фрезер/Акрил 5: 3.5 × 50 × 3 + 2.0 × 1300 × 3 = **8325.00** (2775/шт)
  - Лазер/ПВХ 3 без материала: 0.5 × 15 = **7.50**
  - «Нет ставки» → цена 0 + 2 предупреждения; инъекция конфига без ставок:
    материал считается, рез 0 + warning
  - Валидация: неизвестный станок / qty 0 / толщина < 0 → CalcInputError;
    рез 0 м — разрешён (только материал)
