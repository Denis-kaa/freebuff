## 1. Что сделано

- **Найден legacy-исходник:** «Калькулятор макетов/design_calc.py» (332 строки +
  settings.json). Ключевое отличие от остальных калькуляторов: **формулы НЕТ** —
  цена = позиция прайса по тройке (услуга, сторона 4+N, уровень/вариант);
  `price == 0` → «Цена по запросу» (Вывеска); нет совпадения → «по договорённости».
  Наценка/налог/тираж на цену НЕ влияют — parity сохранён (price == price_no_tax,
  profit = 0).
- **Пакет `printcalc/calculators/design/`** (аддитивно, образец cnc/sign):
  - `config.py` — канонический прайс **дословный порт build_prices()**: 114 позиций,
    42 базовые услуги, 5 категорий (Вёрстка 6, Логотип и стиль 14, Полиграфия 54,
    Широкоформат 30, Прочие 9). Хелперы `services()/sides_for()/options_for()/
    lookup()` повторяют логику JS-фильтров (base name без «4+N», option, side);
    `_base_name` — порт `get_base_name` (regex `\s*4\+\d+\s*`).
  - `spec.py` — CALC-SPEC: service (STRING с 42 опциями из прайса), side
    ("" / 4+0 / 4+4), option (вариант), pages/circulation (не влияют на цену,
    только валидация ≥ 0).
  - `compute.py` — чистая функция: lookup по тройке; найдена → цена; price==0 →
    warning «Цена по запросу»; не найдена → warning «по договорённости» (услуга
    известна, комбинации нет — не ошибка ввода); неизвестная услуга → CalcInputError.
- **Регистрация:** мост `printcalc_web/calculators.py` — register_design + опции
  полей из прайса (service/option). «Дизайн» — 7-й калькулятор реестра.
- **Парсер:** ключевые слова «дизайн», «вёрстк», «верстк», «макет», «логотип»,
  «трассировк» → intent `design` (сегментация входящих).
- **Golden-тесты `test_design_golden.py`** (14 кейсов) с независимой деривацией:
  - Визитка 4+0/Простой = **600**, 4+4/Сложный = **2000**
  - Плакат А3/Средний = **2600**; Ролл-ап/Стандарт = **2250**; Трассировка/Простой = **1000**
  - Вёрстка презентации: pages=1 и pages=10 → обе **750** (тираж не влияет)
  - Вывеска/Премиум = **0** + «Цена по запросу»
  - Фильтр стороны: Листовка без стороны → «по договорённости» (все её позиции 4+N);
    с 4+4/Средний = **1950**
  - Справочник: 114 позиций / 42 услуги / стороны визитки (4+0, 4+4)
  - Валидация: пустая/неизвестная услуга, отрицательный pages → CalcInputError
