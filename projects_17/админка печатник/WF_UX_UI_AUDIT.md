# WF_UX_UI_AUDIT.md — UX/UI аудит WorkflowForms

> Статус: PARTIAL · Дата: 2026-09-07 · Ограничение: интерфейс не запускался (Windows-only, нет сервера и форм) — аудит по строкам/контролам/конфигам.

## 1. Что известно об UI (факты)

- Гибрид WinForms+WPF; контролы: таблицы (фильтры, сортировка, суммы колонок, комбо-колонки, контекстные меню, тёмные/светлые настройки колонок), календари, деревья (Parent/Child), графики LiveCharts, splash-экран (Icons/splash.png), waiting.gif (индикатор загрузки).
- Формы: XML-описания с FormTitle/FormState/BorderStyle, состояние формы сохраняется (RestoreLastFormState, SaveOnFormClose); include-формы (переиспользование).
- Локализация интерфейса: 13 локалей системных ресурсов; собственные строки по ключам.
- Старт: `CopyCentreStart.xml` — рабочий стол копицентра (Г: меню модулей).

## 2. Реестр недостатков (статических)

| ID | Экран | Проблема | Влияние | Приоритет | Решение |
|---|---|---|---|---|---|
| WU-01 | весь | desktop-only Windows-клиент | нет мобильного/веб-доступа | High | целевой web-UI (объединение с PrintCalc) |
| WU-02 | весь | локализация собственных строк не подтверждена (ключи есть, переводы не найдены) | интерфейс может быть частично EN | Medium | проверить при запуске; переводы в целевом |
| WU-03 | формы | дизайн форм скрыт в XML, который не приложен | нельзя оценить UX | Medium | получить формы / спроектировать заново |
| WU-04 | HelpDesk | функциональность неизвестна | нельзя оценить UX-ценность | Medium | декомпиляция/док |
| WU-05 | старт | ошибка «cant_load_start_form» — первый экран при отсутствии сервера | фатальный первый опыт без инфраструктуры | High | в целевом: локальный режим/демо-данные |
| WU-06 | таблицы | богатые гриды (суммы/фильтры) — сильная сторона; сохранить паттерн | — | — | перенести паттерн в web-таблицы |

## 3. Пользовательский путь (восстановлен по конфигу/строкам)

Запуск → splash → загрузка StartForm XML → рендер формы → события (клики/клавиши) → команды (SQL/email/экспорт) → DataConnections обновляют данные → смета/отчёт → сохранение состояния формы. Обновление: клиент раз в 5 минут спрашивает UpdateService.
