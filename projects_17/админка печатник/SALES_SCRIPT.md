# SALES_SCRIPT.md — генератор скрипта для сотрудника

> Статус: COMPLETE (проект) · Дата: 2026-09-07 · Скрипт = другой рендер того же QUESTION_FLOW + ответов. Не отдельная сущность — иначе дрейф, как у прайсов (T-02).

## 1. Модель

```
SERVICE_DEFINITION (вопросы, правила, доп-услуги)
        ↓
ANSWERS (что уже ответил клиент)
        ↓
SCRIPT_RENDERER → 3 слоя:
  A) заранее: «порядок разговора» (чек-лист сотрудника)
  B) во время: следующий вопрос + формулировка + почему
  C) после расчёта: озвучка итога + предложения + следующее слово
```

Генерация основана на (§24): выбранной услуге, ответах, обязательных параметрах, доп-услугах, правилах предприятия (BusinessRules). Всё это — данные.

## 2. Эталонный сгенерированный скрипт: «Клиент: мне нужен баннер»

**A. До разговора (карточка услуги):**
1. Уточнить размер и количество.
2. Спросить, где будет использоваться (влияет на материал и цену).
3. Подобрать материал (440/510 г) и тип печати.
4. Предложить люверсы (шаг 50 см), если крепление верёвкой/рейкой.
5. Для улицы — предложить защиту/обработку края (правило R-03).
6. Уточнить наличие макета; если нет — предложить дизайн (до 3 / до 9 / от 9 м²).
7. Уточнить монтаж (высота) и доставку.
8. Озвучить цену + разбивку.

**B. Во время (пример диалога с состоянием):**

| Шаг | Система показывает сотруднику | Ответ клиента → действие |
|---|---|---|
| 1 | «Спросите размер и сколько нужно» | «3×1 метр, 1 шт» → площадь 3 м², прайс 160/280 ₽/м² (20+ диапазон?) — нет: 3 м² → 200/350 |
| 2 | «Для улицы или помещения?» | «На улицу» → печать = Экстерьерная, люверсы = рекомендуется |
| 3 | «Крепить будете чем? Могу сразу люверсы поставить — 20 ₽/шт» | «Да, по краю» → 2×(3+1)×2/0.5 м шаг... = 16 шт → 320 ₽ |
| 4 | «Макет у вас готов?» | «Нет» → дизайн баннера до 9 м²: 2000–4000 ₽ (M1 прайс) |
| 5 | «Повесить нужно? Это высота…» | «2,5 м, сам повешу» → монтаж нет |

**C. После расчёта (озвучка):**
> «Итак: баннер 3×1 м, 440 г, экстерьерная печать, 16 люверсов, доставка. Печать: 3 м² × 1000 ₽ = 3000 ₽ (экстерьер 0–5 м²: 550/1000). Люверсы: 16 × 20 = 320 ₽. Итого 3320 ₽, готовность — [срок]. Если повесите на сетку — добавим монтаж 600 ₽/м².»

Все числа в примере — из выгруза wide_format.py (экстерьерная 0–5 м² cost/sell 550/1000; люверсы 10/20 ₽/шт). Диалог — PROPOSED-формат, числа EXISTING.

> ⚠️ **Актуальные цены доп. работ — не из этого файла:** с 2026-09-12 цены доп. работ wide
> редактируются владельцем в `printcalc/data/wide_prices.yaml` (runtime, без правки кода;
> РОАДМАП_v7 §10). Люверсы там — 2/40 ₽/шт (поздняя правка владельца из GUI-конфига),
> плоттерная резка — 100/500 ₽/м². Пример выше (16 × 20 = 320 ₽) — учебный; для живой
> озвучки цены сотрудник берёт из расчёта в приложении, а не из скрипта.

## 3. Правила генерации

1. Один скрипт на услугу строится из: обязательных полей → зависимых полей → правил рекомендаций (по убыванию вероятности срабатывания).
2. Формулировки вопросов — редактируемые владельцем (раздел настроек «Скрипты», ADMIN_CONFIGURATION.md §2) — правила конкретного предприятия (§24).
3. Скрипт показывает «почему»: каждое предложение ссылается на правило (R-03 «улица → защита») — сотрудник может объяснить клиенту.
4. Пропущенные вопросы (optional) не попадают в диалог, но отражаются в чек-листе как «не уточнено».
5. Итоговая озвучка = рендер breakdown результата движка (unit_price, строки) — единый источник с сметой PDF/CSV.

## 4. Связь с правами/настройками

- Скрипты хранятся в `scripts.json` (per service) рядом с правилами; отключаемы per-service (§25 «возможность отключения»).
- Шаблоны озвучки: `{price}` `{breakdown}` `{material}` `{lead_time}` — плейсхолдеры результата.
