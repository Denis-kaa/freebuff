## 1. Что сделано

- **Модуль `printcalc_web/margin.py`** — отчёт маржинальности. Себестоимость
  единицы считается ТОЛЬКО движком (cost-калькулятор, канонический конфиг
  `equipment_data.json`) — нулевая дублирующая математика (SSOT).
- **Карта маршрутов `SERVICE_COST_ROUTES`** (закрытый словарь, ANTI-6b):
  8 услуг P0 имеют маршрут «станок + материал + база» (m² / page / a4).
  **Ключевая находка Riso:** мастер RZ300EP — расход НА ЗАДАЧУ (2500 ₽),
  поэтому на qty=1 себестоимость листа = 2504.69 ₽. Маршруты Riso считают
  партию = канонический min_order 500 шт (RISO_BATCH_QTY) — себестоимость
  копии А4 = 9.69 ₽, маржа прайса 15 ₽ = **+35.4%**.
- **Gaps с причинами (не молча):** 12 услуг P0 без маршрута попадают в отчёт
  с закрытым словарём причин SERVICE_GAP_REASONS («нет фотобумаги в конфиге»,
  «составная услуга», «не станочная»). Gap — не ошибка, а задача для владельца.
- **Материалы:** сопоставление реестра с cost_unit конфига по нормализованному
  набору слов (порядок слов/ё-е не важны: «Плёнка самоклеящаяся» ↔
  «Самоклеющаяся плёнка»). purchase_cost=0 → флаг needs_fill.
- **API:** `GET /api/margin/report` — services (сорт. по марже),
  service_gaps, materials, material_gaps, summary (routed/gaps/avg%/below_markup).
- **UI:** страница «Аналитика» (nav «Дальше по плану»): сводка, таблица услуг
  (прайс/себест./цена с наценкой/маржа ₽/% с цветным бейджем ok|warn|danger/
  станок·материал/флаг «ниже наценки»), таблица материалов (закупка vs
  конфиг, Δ), таблица gaps. CSS: .badge.ok/.warn/.danger, .text-danger.

## 3. Ограничения (честно)

- Материалы: закупочные цены в реестре не заполнены (purchase_cost=0) —
  Δ отрицательный до заполнения владельцем; флаг needs_fill подсвечивает.
- Табличка ПВХ/фото-услуги — gaps: составные услуги потребуют маршрута
  из нескольких операций (кандидат Этапа 4+/v2 карты).
- Себестоимость — по дефолтам GUI legacy (наценка 30%, накладные 80к/мес);
  при смене экономики владельцем числа пересчитываются движком автоматически.
