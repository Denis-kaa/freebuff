## Правила ведения реестра

1. Слот → READY только при полном наборе: файл в `images/` + автор + лицензия + подпись из 3 частей.
2. Подпись: «Название → что изображено → для чего используется» (ТЗ §19, дословно).
3. Один файл — один слот (без переиспользования картинки в двух подписях).
4. Если файл в Commons оказался не тем, что казался по имени — статус остаётся TODO, ищем замену; не вписываем «примерно подходящее».
