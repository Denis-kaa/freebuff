## 0. Общие правила (для всех сессий)

| Параметр | Правило |
|---|---|
| Камера | Достаточно смартфона 12+ Мп; штатив или упор (пакет с крупой), таймер 3 с |
| Свет | Рассеянный дневной у окна ИЛИ две лампы под 45° без бликов; **никакой вспышки в лоб** |
| Фон | Нейтральный: белый/серый картон или ровная ткань; в кадре — только то, о чём подпись |
| Масштаб | Для макро — линейка или монета рядом с объектом (важно для толщин/перфорации) |
| Сравнения | Оба образца **в одном кадре** рядом (правило реестра: 1 файл = 1 слот) |
| Ориентация | Горизонтальная (3:2), кроме оговорённых; минимум 1920 px по длинной стороне |
| Именование | Сразу при переносе: `pb-XXX__slug.jpg` из колонки «Целевой файл» — потом не переименовывать |
| Лицензия | Фото мастерской: предлагается CC BY-SA 4.0, автор — мастерская/владелец (решить перед первой загрузкой) |
| Приёмка | Кадр проходит, если виден пункт колонки «Должно быть видно» — иначе пересъём |

3. В `00_photo_bank.md`: строка таблицы TODO → READY + карточка (подпись 3 частей,
   автор = мастерская, лицензия = CC BY-SA 4.0, ссылка на файл локальная).
4. Коммит по каденции: «фотобанк: съёмка в цеху — N слотов (сессия …)».
5. Якобы уже расставлены в главах — новые файлы подхватятся сами.
