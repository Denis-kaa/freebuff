# Глава 19. Визуальная часть — фотобанк учебника

> **ТЗ §19:** учебник обязан быть визуальным; каждая фотография помогает понять предмет;
> подпись «название → что изображено → для чего используется»; где возможно — четыре
> ракурса: (1) материал крупным планом, (2) в работе, (3) готовое изделие, (4) применение.
> Случайные картинки запрещены.
>
> **Эта глава — структура банка и правила работы с ним. Реестр слотов с приоритетами —
> `images/00_photo_bank.md`; приём фото — U13-продолжение в сессии с вебом (сейчас
> веб-поиск лежит, Commons доступен напрямую — источники лицензионно чистые).**

## 19.1. Правила банка

1. **Лицензии:** Wikimedia Commons (CC BY/CC BY-SA/PD) — законно для учебника; каждый
   файл в реестре с автором и лицензией. Скриншоты сайтов поставщиков не используем.
2. **Подпись строго трёхчастная:** «ПВХ вспененный 3 мм → лист белого пластика,
   лёгкий, режется ножом → лица выносных букв, таблички внутри помещений».
3. **Четыре ракурса** — не догма, а максимум: для бумаги хватает «материал крупным
   планом» + «в работе»; для вывесок обязателен ракурс 4 (применение на фасаде).
4. **Сравнения рядом** (главная ценность банка, ТЗ §19): ПВХ vs акрил, Frontlit vs
   Backlit на просвет, ламинированная vs нет, перфорация крупным планом, контражур
   ночью vs днём. Сравнение = два слота, объединённые одним блоком в главе.
5. **Не вставляем то, чего не можем подписать честно.** Слот без подтверждённого файла
   остаётся в реестре со статусом `TODO` — пустого места в тексте главы не будет:
   главы ссылаются на реестр через якорь `📷 [pb-XX]`.

## 19.2. Как глава ссылается на банк

В тексте глав уже проставлены маркеры вида `📷 [pb-XX]` (глава 3 — материалы, глава 5 —
оборудование). Реестр `images/00_photo_bank.md` — единственное место, где слот
превращается в файл+подпись+лицензию. Это Single Source of Truth: одна картинка —
один слот — одна подпись (без дублирования в главах).

## 19.4. Сессия наполнения (когда вернётся веб-поиск / по Commons)

Протокол на один блок (≈30–40 минут):

1. Открыть категорию Commons блока (реестр даёт прямые ссылки на категории).
2. Отобрать файлы по критерию «могу подписать тремя частями без домыслов».
3. Вписать в реестр: имя файла, автор, лицензия, якорь, статус `READY`.
4. Скачать в `images/` (имя = якорь: `pb-014__pvx_srez.jpg`), подпись — в реестр.
5. Прогнать чек: у каждого READY-слота есть файл+автор+лицензия+подпись из 3 частей.
6. Коммит по каденции (блок = коммит).

**Приоритет наполнения:** блок «Сравнения» (ТЗ называет их обязательными) → «Оборудование»
(там новички теряются больше всего) → «Вывески день/ночь» → остальное по главам.
