# Глава 21. Принцип подачи (напоминание автору и студенту)

**Формула объяснения** (ТЗ §21): что это → как выглядит → зачем нужно → где применяется →
пример из реального заказа. Все главы учебника ей следуют; проверка любой карточки — пять вопросов.

**Связи вместо перечислений:** задача клиента → материал → технология → оборудование →
обработка → изделие. Поэтому в каждой главе есть «сквозные» разделы (4.14, 5.16, 6.21,
10.4, 18.7): отдельный факт бесполезен, цепочка — это навык.

**Проверка текста:** если абзац нельзя применить в разговоре с клиентом за 30 секунд —
он не про работу, а про энциклопедию (ТЗ §23: не «красивая энциклопедия», а выход на
уровень уверенного начинающего).

# Глава 22. Финальные шпаргалки

## 22.1. «Что спросить у клиента» — универсальный чек-лист

Пять обязательных (любой заказ):

1. **Что именно** и в каком размере (см, точно).
2. **Сколько** штук.
3. **Где будет** использоваться (внутри/снаружи/на чём клеить).
4. **Макет есть?** (если нет — разговор о дизайне).
5. **Срок** (фиксировать письменно).

Плюс по типу заказа (ветки гл. 15): крепёж/монтаж (баннер, вывеска, табличка),
документ (фото), ткань (футболка), форма (наклейка), единица пакета (фото).

**Запрещено спрашивать то, что выводится:** площадь, число люверсов, раскрой, цену — считает приложение.

## 22.2. «Как определить материал» — дерево решений

```
ВНУТРИ или СНАРУЖИ?
├─ СНАРУЖИ (улица, фасад, авто)
│   ├─ Большой формат (≥ 9 м²) или перетяжка → баннер 510 г / сетка (ветер) [R-04]
│   ├─ Плоскость жёсткая, солнце → КОМПОЗИТ (ПВХ поведёт)
│   ├─ Оклейка кривой поверхности/авто → плёнка + ЛАМИНАЦИЯ обязательна
│   └─ Долгий срок (год+) → UV-краски / экстерьерная печать
└─ ВНУТРИ
    ├─ Держат в руках (визитки, сертификаты) → бумага 250–300 г
    ├─ Вешают на стену краткосрочно → баннер 440 / постерная бумага
    ├─ Смотрят вблизи долго (интерьер, офис) → интерьерная 1440, холст/бэклит
    ├─ Двери/стены офиса → ПВХ 3 мм (бюджет) / акрил (премиум)
    └─ Сгибается (брошюры) → 130–170 г, от 170 г — биговка
```

## 22.3. «Как определить технологию» — дерево решений

```
ЧТО ЗА МАТЕРИАЛ ПРЕДМЕТА?
├─ Бумага/картон, малый тираж → цифровая (электрография)
├─ Бумага немелованная, тираж ≥ 100–500 одного макета → ризограф
├─ Плёнка/баннер рулонный → эко-сольвент
├─ Жёсткий лист (ПВХ, композит, акрил) → UV
├─ Полиэстер (флаг, кружка с покрытием) → сублимация
├─ Хлопок → DTF (полноцвет/малый тираж) или шелкография (1–2 цвета, 20–30 шт)
├─ Фото (тон, бумага) → минилаб D2T2
└─ Чек/бирка → термо / термоперенос
```

Правило кассы одной строкой (гл. 4.0): **баннер → эко-сольвент/UV, хлопок → DTF,
полиэстер → сублимация, бумага → цифра или ризо по тиражу.**

## 22.4. «Какую резку выбрать» — сравнительная таблица

| Ситуация | Резка | Оборудование | Цена |
|---|---|---|---|
| Прямоугольник, лист, стопа | ровный рез | гильотина | дешёво |
| Фигура по вектору из макета | контурная | режущий плоттер (OP-22) | за м² |
| «Порезать поштучно» | контурная поштучно | плоттер, отдельный контур на элемент | за м² |
| Бирки/отрывной | перфорация | плоттер/биговщик | работа |
| Толстый лист (ПВХ 3–5, акрил) | фигурная | фрезер CNC / лазер (ПВХ лазером НЕТ) | за м²/работа |
| Углы визитки/таблички | скругление | уголок/фрезер | за копию |

Перед любой контурной: макет с замкнутым спот-контуром? усадка 12–24 ч отлежалась?

## 22.5. «Когда нужна ламинация» — шпаргалка

| Сценарий | Ламинация | Почему |
|---|---|---|
| Авто, пол, пол | **ДА** | истирание, мойка |
| Улица сезон+ | **ДА** | UV, влага |
| Витрина долгая | ДА | выцветание |
| Помещение < 1 года | НЕТ | переплата |
| Прозрачная «для блеска» | НЕТ | анти-ситуация |
| Перфорация (One Way Vision) | НЕТ* | заклеишь дырки (*если не требуют — честно предупреди) |

## 22.6. «Материал для улицы» — шпаргалка

Баннер 440 (до 9 м²) → 510/литой (9+, сварка) → сетка (ветер, фасады) → композит
(жёсткое, солнце) → плёнка+ламин (авто/витрина). Печать — экстерьерная. БП/электрика
для светых — R-09; монтаж от 5 м — автовышка +30 % (R-10).

## 22.7. «Материал для помещения» — шпаргалка

Бумага 130–170 (листовки) → 250–300 (визитки) → ПВХ 3 (таблички) → акрил/композит
(премиум) → холст/бэклит (интерьер 1440). Печать — интерьерная (тир 450→350 ₽/м²).

## 22.8. «Как подготовить файл» — чек-лист (из гл. 14.5)

1. Формат изделия в мм + вылеты 2–5 мм.
2. CMYK, не RGB (неон в красках не существует).
3. Текст в кривых (шрифт не улетит).
4. Мелкий чёрный текст = K100, не композитный C50M40Y40K100.
5. Прозрачности/overprint — проверить, не «пропало» ли.
6. Плотность: 300 ppi в руках, 150 — плакат, 70 — баннер.
7. Контур реза: замкнут, спот-цвет, 0.25 pt, отдельным слоем.
8. JPEG с телефона — не макет, повод для разговора о дизайне.

## 22.9. «Что проверить перед запуском» — чек-лист производства

1. Заказ в приложении: параметры = разговору (размер, тираж, обработка).
2. Материал в наличии и подходит (рулон шире изделия? гл. 10).
3. Макет принят по чек-листу 22.8 (для контура — пункт 7 обязателен).
4. Операции каталога назначены (люверсы шаг, карман, ламин) — цена пересчитана.
5. Оборудование свободно, материал загружен, пробный оттиск согласован клиентом (цвет!).

## 22.10. «Что проверить перед выдачей» — чек-лист контроля

1. Размер и тираж факт vs заказ.
2. Цвет/качество: нет полос, не смещён рез, кромки чистые.
3. Постпечать: люверсы по шагу из заказа, карманы ровные, ламин без пузырей, сгибы по биговке.
4. Контурная резка: контур по линии, выборка чистая, плёнка не порвана (чек-лист OP-22).
5. Комплектность: монтажная на месте, крепёж приложен, шаблон для букв включён.
6. Упаковка: рулоны не заломлены, стопы переложены, брошюры в пачках.
7. Выдача: показать, озвучить «как крепить/клеить», напомнить срок эксплуатации (улица!).

## Финальная фраза (ТЗ §23)

Заказ клиента → изделие → материал → технология → обработка → вопросы → задание
производству. Если после всех глав ты можешь провести эту цепочку по любому из 30
кейсов гл. 18 без подсказок — учебник свою работу сделал. Дальше навык растёт только
в зале: у станка, с клиентом и с приложением «Печатник», которое держит терминологию,
цены и проверки за тебя.
