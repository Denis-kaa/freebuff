# Глава 20. Источники

## 20.1. Как устроена достоверность в учебнике

Каждая фактическая характеристика снабжена грейдом (протокол `research/00`):

| Грейд | Что это | Пример в учебнике |
|---|---|---|
| **A** | производитель/первоисточник/живой код проекта | ORACAL 641 — 75 мкм (карточка производителя); RISO RZ300EP — калькулятор платформы |
| **B** | проф. каталог, энциклопедия | ряды плотностей меловки; Wikipedia по техпроцессам (B+) |
| **C** | агрегатор/магазин | толщины рулонов |
| **D** | форум/анекдотическое | только как «реальная цитата клиента», не как факт |
| **E** | не найдено | честное «по запросу» (9×12, ламинация А2/А1) |

Правила: расхождения производителей — не прятать, а таблицей «зависит от…»;
«типично/ориентир» — помечать в тексте (температуры прессов, сроки службы);
цены — только из живого каталога проекта, в учебнике не живут.

## 20.3. Как искать самому (для новичка — навык, не глава)

1. **Характеристика материала** → сайт производителя → карточка товара → PDF-паспорт.
   Магазинные карточки — вторичны (перепечатывают производителя).
2. **Проверка цены** → живой каталог приложения; внешние прайсы — только для «рынок района»
   (research/03), не для озвучки клиенту.
3. **Требования документа** (фото, бланки) → официальный источник ведомства, не форум.
4. **Спор с клиентом о терминах** → гл. 16 (словарь) + CONTEXTUAL_HELP приложения.
5. Всё, что нашёл сам и использую в работе → записать в глоссарий проекта (правило
   REGISTER-FIRST: новое знание фиксируется, а не живёт в голове).

# Глава 21. Принцип подачи (напоминание автору и студенту)

**Формула объяснения** (ТЗ §21): что это → как выглядит → зачем нужно → где применяется →
пример из реального заказа. Все главы учебника ей следуют; проверка любой карточки — пять вопросов.

**Связи вместо перечислений:** задача клиента → материал → технология → оборудование →
обработка → изделие. Поэтому в каждой главе есть «сквозные» разделы (4.14, 5.16, 6.21,
10.4, 18.7): отдельный факт бесполезен, цепочка — это навык.

**Проверка текста:** если абзац нельзя применить в разговоре с клиентом за 30 секунд —
он не про работу, а про энциклопедию (ТЗ §23: не «красивая энциклопедия», а выход на
уровень уверенного начинающего).

# Глава 22. Финальные шпаргалки

## 22.1. «Что спросить у клиента» — универсальный чек-лист

> Основание: гл. 15 (скрипты), QUESTION_FLOW. Порядок важен — каждый следующий вопрос
> зависит от предыдущего ответа.

1. Что за изделие? (своими словами — нормализует приложение, но уточни своими: «наклейка — на что клеить?»)
2. Размер? (в см, Ш×В; «примерно» — не ответ)
3. Сколько штук? (порог тиража покажи сразу)
4. Где будет использоваться? (улица/помещение/авто — определяет материал и защиту)
5. Форма? (прямоугольник / фигурная)
6. Крепление/монтаж? (люверсы, скотч, винты, вышка)
7. Макет есть? (если нет → дизайн, уровень)
8. Срок?

*Всё остальное приложение выведет само. Не задавай вопросы, на которые можешь ответить расчётом.*

## 22.2. «Как определить материал» — дерево

> Основание: гл. 3, 8.2.

```
Где будет жить изделие?
├─ Улица
│   ├─ Гнётся? → баннер 440/510 (литой, если сварка/натяжка)
│   ├─ Плоское жёсткое? → композит (не ведёт) · бюджет → ПВХ+УФ-лак
│   ├─ На стекло/авто? → плёнка + ламинация обязательна
│   └─ Сетка/ветер? → баннерная сетка
├─ Помещение
│   ├─ Плоское? → ПВХ 3 мм (бюджет) · акрил (премиум)
│   ├─ Бумага? → мелованная 130–300 г (ризо — ТОЛЬКО немелованная!)
│   └─ Интерьер-панно? → холст / интерьерная печать
└─ Тело/ткань
    ├─ Полиэстер → сублимация
    └─ Хлопок → DTF
```

## 22.3. «Как определить технологию» — дерево

> Основание: гл. 4 (13 технологий), сводная таблица 4.14.

```
Что печатаем?
├─ Бумага, тираж < 100 → цифровая (электрография; тонер = печка ~160–200 °C)
├─ Бумага, тираж ≥ 100–500, немелованная → ризограф (дешевле, 1+0/1+1)
├─ Плёнка/баннер рулонный → эко-сольвент (выдержка 12–24 ч до резки!)
├─ Жёсткий лист (ПВХ, композит, акрил) → UV (мгновенная полимеризация)
├─ Полиэстер/текстиль → сублимация (краска входит в волокно)
├─ Хлопок → DTF (аппликация на ощупь) · DTG (мягче, но претрейтмент)
├─ Фотобумага → минилаб D2T2 (непрерывный тон)
└─ Чек → прямая термо (выцветает «по свойству бумаги» — это норма)
```

## 22.4. «Какую резку выбрать» — таблица

> Основание: гл. 6 (6.2–6.4а), гл. 9.

| Ситуация | Резка | Оборудование | Цена за |
|---|---|---|---|
| Прямоугольник из листа | ровный рез | гильотина | рез/лист — дешевле |
| Силуэт (фигура) | контурная | режущий плоттер (OP-22) | м² |
| «Поштучно» из листа | контурная поштучно | плоттер + выборка | м² + время выборки |
| Наклейки одинаковые мелкие | раскрой листа | гильотина | лист |
| Табличка по размеру | подрезка | фреза/гильотина | шт |
| Буквы/аппликация | плоттерная | плоттер | м² |
| Сгиб | фальц/биговка | фальц-машина/биговщик | сгиб |

*Контурная резка = вектор из макета: контур замкнут, спот-цвет, 0.25 pt (гл. 14.3).*

## 22.5. «Когда нужна ламинация» — шпаргалка

> Основание: гл. 9 (таблица 9.2), R-07.

- ✅ **Обязательно:** автомобиль, пол/пол, витрина снаружи, всё уличное с касанием рук
- ✅ **Сильно желательно:** листовки в дождь? нет — но сертификаты в папках, меню, карточки в карманах
- ⚪ **По желанию:** интерьерные наклейки < 1 года (продай как опцию с причиной)
- ❌ **Не нужна / вредна:** поверх перфорации (закроешь дырки), «прозрачную ради блеска» (станет мутной), бумага для ризо (не ламинируется тонер-мазею — сначала дай остыть)
- ⚠️ **Порядок:** ламинация ДО скругления, не после (гл. 17, ошибка №41)

## 22.6. «Материал для улицы» — шпаргалка

> Основание: гл. 3, 7, 8, R-03/R-04.

| Ситуация | Материал | Почему |
|---|---|---|
| Баннер < 9 м² | 440 г ламинированный | бюджет-стандарт |
| Баннер ≥ 9 м² | 510 г литой | прочнее, под сварку/натяжку (R-04) |
| Перетяжка через улицу (ветер) | баннерная сетка | ветропроницаема, не парусит |
| Фасадная плоская табличка | композит 3–4 мм | не ведёт на солнце |
| Временная табличка улица | ПВХ 3 мм + УФ+лак | дешевле, но ведёт со временем — честно скажи |
| На стекло/авто | плёнка + ламинация | без ламинации выцветет/поцарапается |
| Светящееся лицо | молочный акрил 3 мм | рассеивает равномерно |
| Требования: мороз | литой/спец. баннер | ламинированный дубеет и трескается на сгибе (−30 °C граница, ориентир) |

## 22.7. «Материал для помещения» — шпаргалка

| Задача | Материал | Примечание |
|---|---|---|
| Визитки/листовки | мелованная 300/130–170 г | тир цены по тиражу |
| Ризо-тираж | НЕмелованная 60–80 г | соевая краска должна впитаться! |

| Интерьер-панно | холст/бумага рулонная, интерьерная печать | 1440 dpi оправдан (смотрят вблизи) |

## 22.8. «Как подготовить файл» — чек-лист

> Основание: гл. 14 (чеклист приёмки 14.5).

1. Размер = изделие + вылеты 2–5 мм (вылет уходит ПОД рез).
2. Цвет — CMYK; неоновое обещать нельзя; белый — отдельный канал.
3. Мелкий текст — K100, не композитный чёрный.
4. Шрифты в кривых (или приложены).
5. Растр: 300 ppi листовка · 150 постер · 70 баннер · 30 перетяжка (по дистанции).
6. Контур реза: замкнутый, спот-цвет, 0.25 pt, отдельным слоем.
7. Прозрачности/overprint — сгладить/проверить.
8. JPEG с телефона — не макет; повод поговорить о дизайне.

## 22.9. «Что проверить перед запуском» — чек-лист производства

> Основание: гл. 5–6, 17.

- [ ] Материал соответствует назначению (улица/интерьер — сверить с заказом)
- [ ] Рулон достаточной ширины (PRODUCT_DOES_NOT_FIT — проверить ДО обещания клиенту)
- [ ] Расход посчитан раскладкой, не геометрией
- [ ] Стыки/швы сварки — не по лицу макета
- [ ] Плёнка отлежалась 12–24 ч (эко-сольвент) перед резкой
- [ ] Проба реза на одном экземпляре (давление ножа)
- [ ] Люверсы: шаг из заказа (30 см ≠ стандартные 50!)
- [ ] Монтаж: высота → вышка (+30 % от 5 м), электрика на месте
- [ ] Брошюра: кратность 4, развороты собраны по порядку

## 22.10. «Что проверить перед выдачей» — чек-лист контроля качества

> Основание: гл. 6.21 (чек-лист OP-22 как образец), 17.

- [ ] Размеры изделия = заказу (померить, не «на глаз»)
- [ ] Цвет без полос/засветов; вылеты отрезаны — белой кромки нет
- [ ] Рез: плёнка не порвана, контур ровный, выборка чистая
- [ ] Люверсы: все на месте, шаг ровный, кольца не режут текст
- [ ] Ламинация без пузырей и отслойки по краям
- [ ] Брошюра: страницы по порядку, скрепки на месте, сгиб без трещины
- [ ] Тираж сходится: N штук фактически, брак сверх нормы пересчитан
- [ ] Упаковка: наклейки с защитной прокладкой между слоями
- [ ] Заказ в приложении закрыт, файл клиента сохранён

## Как пользоваться шпаргалками (и почему их всего десять)

Каждая закрывает один момент решения у кассы: вопрос → материал → технология → резка →
защита → файл → запуск → выдача. Это те же ступени, что проходит «Печатник» за сотрудника:
нормализатор (22.1–22.3), движок правил (22.4–22.7), мост в калькулятор (22.8–22.10).
Шпаргалка — для головы и рук; приложение — для цен и расхода. Вместе — уверенный
начинающий специалист, к которому и ведёт весь учебник (ТЗ §23).
