> **Назначение:** человек без опыта после изучения понимает материалы, технологии,
> оборудование, изделия — и умеет разговаривать с клиентом и передавать заказ в
> производство (ТЗ `promt_pecatnik_10.md` §23). Статус: **v1 собран** (U0–U15), см.
> `../TEXTBOOK_REPORT.md`.

> Цены и расход всегда — из расчёта приложения «Печатник»; в учебнике они ориентиры.

## Сквозные разделы (собирают курс в навык)

- **4.14** — какой макет на какой технологии (таблица 13 строк);
- **5.16** — заказ клиента → класс машины (таблица golden-фраз);
- **6.21** — пять правил приёмщика (единица цены, ничего молча);
- **10.4** — расход ≠ геометрия (живые прогоны движка);
- **18.7** — карточка кейса = конвейер Smart Order (распознать→нормализовать→проверить→предложить→посчитать);
- **22.1–22.10** — шпаргалки у кассы (распечатать).

## Связь с платформой

Учебник — предметный слой «Печатника»: golden-фразы = эталоны нормализатора (S1),
чек-листы операций = OP-01…OP-22, словарь = TERMS_GLOSSARY, правила разговора =
QUESTION_FLOW/SALES_SCRIPT. Терминология глав совпадает с токенами паков правил
(closed vocabulary, ANTI-6b) — учебник можно использовать как источник для расширения
словарей после REGISTER-FIRST-регистрации новых токенов.

## Правила ведения

1. Новая глава/правка — аддитивно, с сохранением протокола источников (`00_sources.md`).
2. Характеристики — с источником или с пометкой «типично/ориентир»; расхождения — таблицей «зависит от…».
3. Фотобанк — только через реестр `images/00_photo_bank.md` (файл+автор+лицензия+подпись).
4. Цены в тексте не живут: живые — приложение/прайс владельца.
