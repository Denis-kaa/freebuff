## 2. Пользовательские сценарии MVP (каждый законченный)

1. Открыть `/` → выбрать «Ризограф» → ввести формат/тираж/бумагу → «Рассчитать» → видит цену/себестоимость/прибыль → «В смету».
2. Добавить 2–3 позиции из разных калькуляторов → `/estimate` → «Сохранить CSV».
3. Открыть `/settings`-файл реестра → поправить цену бумаги → пересчёт даёт новую цену.
