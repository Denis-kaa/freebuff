## 2. Услуга-словарь S-01: Широкоформат (факт из wide_format.py:20-77)

**Материалы** (cost/sell ₽/м², диапазоны по площади):
- Баннер 440г: 200/350 (0–5 м²) → 180/300 (5–20) → 160/280 (20+)
- Баннер 510г: 250/420 → 230/380 → 210/350
- Плёнка самоклеящаяся: 320/600 (0–3) → 300/550 (3–10) → 280/500 (10+)
- Холст: 400/700 (0–2) → 380/650 (2+)

**Печать** (₽/м²): Интерьерная 450/800→350/650; Экстерьерная 550/1000→450/800; УФ 800/1400→700/1200; Без печати 0.
**Монтаж** (7 вариантов): без подъёма 1000/2500 (до 2 м) … автовышка 6000/10000 (свыше 3 м).
**Доп-работы**: Загибка м 100/200; **Люверсы шт 10/20** (`is_grommet`, шаг по умолчанию 50 см, wide_format.py:143); Карман м 250/400; Накатка на жёсткую основу м² 500/900; Монтаж на баннерную сетку м² 300/600.
**Ставки**: печать cost 150 / sell 250 ₽/м²; доставка 500/1200; мин.сумма заказа — настройка UI (wide_format_config.json).

## 3. S-02 Таблички (tablichki.py:25-64)

**Материалы** (cost/sell): ПВХ 3мм 800/1200, ПВХ 5мм 1000/1500, Акрил 3мм 1300/1800, Акрил 5мм 1700/2200, Композит 3мм 1200/1600, Композит 5мм 1500/1900.
**Печать**: УФ 1500/2400; УФ+лак 2000/3000. **Крепёж**: скотч 20/35, клейкая пена 40/60, винты(4шт) 25/40, дюбели(4шт) 40/60.
**Обработка**: Скругление углов м² 100/200; Фрезеровка сложной формы м² 500/800; Скотч по периметру м 70/120; **Люверсы шт 20/35** (в wrapper — «шт», в standalone — «м», см. T-02).
**Ставки**: работа 400/1000; доставка 100/300; MIN_ORDER 0; налог 6%; коэффициенты сложности Простой/Средний/Сложный = **1.0/1.0/1.0** (заглушка, не влияют).

## 4. S-03 Вывески/буквы (sign_calc.py:22-88)

**Модели** (work_rate ₽): Наличная 1000, Объёмная 1500, Контражур 2500 (свет), С подсветкой 3000 (свет), Световой короб 1800 (свет). Единицы: буквы «cm» (ширина = 0.7×высоты, INFERRED из расчёта), короб «sqm».
**Материалы** ₽/м²: ПВХ 3/5/10мм 350/450/700, Акрил 3/5мм 1500/2200, Композит 3мм 1800, Алюкобонд 4мм 2300. Части (PART_DEFAULTS): лицевая/боковая/задняя + side_height.
**Каркас**: Металлический 300, Профтруба 350, Деревянный 200. **Нанесение**: УФ 1200, Аппликация плёнкой 600.
**Монтаж**: база 3500 ₽ + % по высоте (до2м 0, 2–3м 10, 3–5м 20, от5м 30). **Электрика**: база 800 + 350 ₽/м; БП 1200. **Доставка**: 40 ₽/км. Налог 6%, наценка по умолчанию 25%.
⚠️ **PRICE_PER_CM = 0 у всех 5 моделей** (sign_calc.py:60-67) — режим «прайс ₽/см» пуст из коробки; фактическая цена считается через себестоимость×наценка.

## 5. S-04 Ризограф (riso_calc.py:26-96; перенос в printcalc/riso/config.py)

Форматы A4/A5/A6/A3 (A3 = A4×2.0); цветность ч/б/1 краска/2 краски; двусторонность; тираж с MIN_ORDER 500.
**Прайс ₽/лист** (одна/две стороны): A4 0.50/0.90 → 0.25/0.45 (6 диапазонов); A5 0.30/0.55→0.15/0.30; A6 0.20/0.35→0.10/0.20.
**Себестоимость**: бумага 0.02–0.10 ₽/лист (5 видов), краска ч/б 0.02/1к 0.05/2к 0.09, мастер 5 ₽/шт, работа 50 ₽/1000.
**Доп-услуги**: резка 100, ламинация 2 ₽/лист, фальцовка 0.5 ₽/лист, степлер 10, доставка 500. Налог 6%; наценка на мастера+допы (UI-параметр).

## 6. S-05 Цифровая печать (digital_calc.py:20-101)

**Бумага** ₽/лист: Офсет 80 (0.35), Офсет 90 (0.45), Мел.мат 115 (0.90), Мел.глян 130 (1.00), Мел.мат 170 (1.50), Мел.глян 300 (2.30), Картон 250 (1.80), Самоклейка (1.60). **Краска**: ч/б 0.10, цветная 1.20 ₽/лист.
**Изделия-шаблоны** (9): Визитка 90×50, Листовка А5/А4, Евробуклет, Календарь карманный, Открытка, Открытка в развороте, Приглашение, Сертификат.
**Тиражный прайс ₽/изд**: Визитка 4/3/2 (1–100/101–500/500+); Листовка А5 8/5/3; А4 12/8/5; прочие default 10.
**Постоперации**: Ламинация 1.5/лист, Фальцовка 0.3/лист, Резка 2.0/лист, Скругление углов 8/копия, Скоба 15/копия, Пружина 70/копия. Приладка SETUP_COST 100; мин.заказ 500; наценка default 30%. Раскрой: форматы A4/A3/SRA3, зазор 2 мм.
**Разрешённые единицы (код!)**: `ALLOWED_UNITS = ["лист","копия","заказ","шт","м","м²"]` (digital_calc.py:41).

## 7. S-06 ЧПУ (cnc_settings.json) и S-07 Дизайн (settings.json)

**ЧПУ**: 13 материалов (Фанера 3–18 мм 300–1200 ₽/м²; Акрил 800–1300; ПВХ 500–800; Композит 1500–1900), 17 ставок резки ₽/м (laser 15–80, frezer 35–90). CRUD в UI → JSON.
**Дизайн**: 5 категорий (Вёрстка / Логотип и стиль / Полиграфия / Широкоформат / Прочее), 114 позиций {name, option, category, price}; уровни Простой/Стандарт/Премиум (или Средний/Сложный); стороны 4+0/4+4. Примеры: Вёрстка каталога 455 ₽/полоса; Логотип (2 варианта) 2500–3900 ₽; Фирменный стиль полный 25 000 ₽; **Дизайн баннера до 3 м² 1000–2500, до 9 м² 2000–4000, от 9 м² 3000–6500 ₽**; «Вывеска» — **0 ₽ (заглушка)**. Отделка (7): Ламинация, Выборочный УФ-лак, Тиснение фольгой, Скругление углов, Перфорация, Биговка.
